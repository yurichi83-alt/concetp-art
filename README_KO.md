**시작:** `START_HERE_KO.md`의 요청을 Codex에 한 번 입력하세요. 이후에는 짧은 장면 키워드만 사용합니다.

> 예: `교역장 / 밤 / 드럼통 / 한 장`

## 기본 동작
1. 짧은 키워드를 읽고 새 장소인지 기존 장면 편집인지 구분합니다. 새 장소는 건축·배치·단면을 다시 설계합니다.
2. 원본 01·02를 구도 기준으로, 03을 표현 기준으로, 04를 디자인 언어로 사용합니다.
3. 도구가 지원하는 실제 이미지 입력을 이용해 참조를 전달합니다. 경로를 문장으로만 쓰고 첨부했다고 주장하지 않습니다.
4. 내장 생성 기능으로 요청 장수를 최종 목표로 만듭니다. 실제 구조 오류는 자동 수정·재생성하고 재검수합니다. 별도 API/설치는 동의 없이 사용하지 않습니다.
5. 파일 접근이 가능하면 결과와 브리프를 보관하고, 실제 눈으로 확인 가능한 검수만 기록합니다.

## 변경 관리
- 원본은 수정·크롭·재압축하지 않은 복사본입니다. 파일 이름만 역할에 맞게 바꿨습니다.
- 이번 장면 키워드는 기존 규칙에 추가되며, 마스터를 자동으로 덮어쓰지 않습니다.
- “이번만 중앙에 구조물 허용”은 해당 장면의 예외로 기록하고, “앞으로 기본값 변경” 요청에서만 기준 문서를 수정합니다.
- 이전 생성물은 사용자가 승인한 항목만 재사용합니다. 색감 승인은 구도/재질 승인과 다릅니다.
- 외부로 공유하거나 버전 저장소에 공개 업로드하지 않습니다. 원본 참조 이미지는 사용자가 제공한 시각 자료이며 이 패키지가 저작권 이용허락을 새로 부여하지 않습니다.

## 검증
```bash
python3 scripts/validate_project.py
```
파일 존재·이미지 해시·경로·핵심 구성만 검사합니다. 이미지 스타일이나 출구 개수를 자동 판정하는 프로그램이 아닙니다.

문서 정리 기준일: 2026-09-12. 패키지1.7.0 / 참조 목록2026-09-12-architecture-form-01. 제품 동작 관련 출처: `docs/09_SOURCES.md`.

현재 표면 표현은 넓고 깨끗한 기본 색면에 가까운 톤의 크고 성긴 방향성 붓터치를 일부 배치합니다. 온전한 면에도 쓰는 평면 색 변화이며 손상량과는 별개입니다. M03-10은 대표로 유지하고 B03 보조의 표면 선호를 기하·전체 결과 승인으로 확대하지 않습니다. 승인 `master_update_20260911_v2_6_brush_planes`, 상세 표현·검수는 `docs/03_VISUAL_STYLE_V2.md`와 `docs/06_QA.md`를 따릅니다.

## 현재 기하·형태·동선
공통 정육면체형 공간과 하나의 투영에서 구조안을 먼저 만들고 아트 적용 뒤 최종 결과를 대조합니다. 기본 블록 기하(C03), 공통 투영(C04), 내부 동선(L06)과 이미지에 보이는 보행 공간을 검사합니다. 구조 FAIL/핵심 불확실은 전체 합격으로 처리하지 않습니다.

현재 v2.7/실행1.8에서는 단일 정사영·정사각 베이스·두 전면 평면 단면을 유지한다. 건물의 주된 배치와 직선 구조는 공통 X/Y축을 따르며 지상 곡면 외벽과 둥근 기계형 건축도 허용한다. 큰 형태·외벽 깊이·후퇴/돌출·계단·데크·지붕과 설비 결합으로 차이를 만들고, 임의 회전이나 좁은 쐐기 틈은 피한다. 기계는 특정 층 자체의 비거주 설비 부피가 될 수 있지만 모든 건물의2층에 강제하지 않는다. 건물 곡면 허용은 베이스의 둥근 테두리·모따기 허용이 아니다. 약11시/1시 방향의 기능 출구 두 개는 면 안 위치/형태가 자유이며 건물 입구 겸용·클리어 전 닫힘도 가능하다. 경계는 건물·설비·차량 등으로 연결하고 출구 상태와 개방 후 연결을 기록한다. 건물에만 입구·옥상40~80% 규칙을 적용하며 장면별 기계 비중과 구분한다. 콜리전·메시·UV 검증은 이미지 합격 조건이 아니며 보이는 접지·지지·연결·동선은 검사한다.

F-01~07은 큰 형태·외벽 깊이만 참고하는 선택 가능한 건축 형태 보강 자료이며 기본 입력은 아니다. F-08~11은 형태 선호 비교용으로만 사용하고 생성 입력이나 기하 승인으로 취급하지 않는다. 기존 마스터27장·표면 보조4장과 M03-10/M04-02 우선순위를 유지하며 F 예시의 기존 needs_revision 판정도 보존한다. 특정 L형·기계층·40%/20%·건물 수·소품·기후를 다음 장면의 기본값으로 고정하지 않는다.

실행 지시는 templates/generation_prompt.md의 구조→현재 장면→아트/참조 역할 순서로 압축하고 요구사항 대응표로 누락을 확인한다. 실제 최종 이미지의 같은 축 선군·상하 대응 모서리를 필수 정사영 기준으로 검수하며, 가려진 핵심 근거는 불확실로 남긴다. 도구 입력 길이/장수는 실제 전달값과 확인된 제한을 구분해 기록한다.
