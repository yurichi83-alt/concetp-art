# GameConcept_Codex

**시작:** `START_HERE_KO.md`의 요청을 Codex에 한 번 입력하세요. 이후에는 짧은 장면 키워드만 사용합니다.

> 예: `교역장 / 밤 / 드럼통 / 한 장`

## 들어 있는 것
- 마스터 01~04 v2 원칙과 생성 실행 규칙 v1
- 사용자 제공 원본 레퍼런스 19장(구도 1, 공간 도해 1, 시각 스타일 10, 세계관/적 디자인 7)
- 검토용 이전 생성물 3장 — 양성 스타일 기준과 분리
- `AGENTS.md`와 로컬 작업 스킬 `game-env-art`
- 매번 사용할 생성 브리프·참조 전달 기록·검수 기록 템플릿
- 별도 설치 없는 Python 표준 라이브러리 기반 파일 무결성 검사
- 원본의 역할을 한눈에 확인할 수 있는 `REFERENCE_INDEX.html`

## 디렉터리
```text
GameConcept_Codex/
├─ AGENTS.md                 # Codex 프로젝트 진입 지침
├─ START_HERE_KO.md          # 첫 사용 안내와 복사할 요청

├─ REFERENCE_INDEX.html     # 로컬 원본 갤러리
├─ project.json              # 프로젝트 데이터. Codex의 전역 config 아님
├─ .agents/skills/game-env-art/
├─ docs/                     # 마스터·실행·검수·초기 진단
├─ refs/                     # 원본 19장, 역할별 폴더
├─ review_only/              # 실패/부분 승인 시안. 기본 생성 입력 금지
├─ templates/                # 생성 기록 양식
├─ scripts/validate_project.py
├─ outputs/                  # 새 생성 결과와 기록
└─ state/                    # 세팅 상태와 승인 내역
```

## 기본 동작
1. 짧은 키워드를 읽고 변경분만 파악합니다.
2. 원본 01·02를 구도 기준으로, 03을 표현 기준으로, 04를 디자인 언어로 사용합니다.
3. 도구가 지원하는 실제 이미지 입력을 이용해 참조를 전달합니다. 경로를 문장으로만 쓰고 첨부했다고 주장하지 않습니다.
4. 내장 생성 기능으로 요청한 장수만 만듭니다. 별도 API/설치는 동의 없이 사용하지 않습니다.
5. 파일 접근이 가능하면 결과와 브리프를 보관하고, 실제 눈으로 확인 가능한 검수만 기록합니다.

## 변경 관리
- 원본은 수정·크롭·재압축하지 않은 복사본입니다. 파일 이름만 역할에 맞게 바꿨습니다.
- 이번 장면 키워드는 기존 규칙에 추가되며, 마스터를 자동으로 덮어쓰지 않습니다.
- “이번만 중앙에 구조물 허용”은 해당 장면의 예외로 기록하고, “앞으로 기본값 변경” 요청에서만 기준 문서를 수정합니다.
- 이전 생성물은 사용자가 승인한 항목만 재사용합니다. 색감 승인은 구도/재질 승인과 다릅니다.
- 외부로 공유하거나 버전 저장소에 공개 업로드하지 않습니다. 원본 참조 이미지는 사용자가 제공한 시각 자료이며 이 패키지가 저작권 이용허락을 새로 부여하지 않습니다.

## 검증

```bash
python3 scripts/validate_project.py
```
