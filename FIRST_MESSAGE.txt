이 폴더를 내 게임 배경 컨셉아트 작업 프로젝트로 사용해줘. 새 웹앱이나 이미지 생성 프로그램을 개발하는 요청은 아니야.

AGENTS.md와 START_HERE_KO.md를 읽고, 마스터 세트 v2.7·생성 실행 규칙 v1.8·원본 레퍼런스 경로를 확인해줘. scripts/validate_project.py로 파일 누락도 확인해줘.
이후에는 내가 “장소 / 시간대 / 소재 / 한 장”만 입력해도 기존 공간과 스타일 규칙을 유지해서 바로 이미지를 생성해줘.

현재 환경의 내장 이미지 생성 기능과 imagegen 스킬 사용 가능 여부를 먼저 확인해줘. 사용 가능하면 그 기능을 사용하고, 별도 과금 API나 추가 설치가 필요하면 실행 전에 알려줘. 전역 설정은 바꾸지 마.

준비가 되면 별도 재확인 없이 첫 테스트를 진행해줘:
교역장 / 밤 / 드럼통 / 한 장

정육면체형 공통 공간과 필수 정사영으로 구조안을 먼저 잡고, 중앙부터 두 출구 너머까지 물체가 침범하지 않는 보행 공간을 확보해줘. 베이스 상하 대응/평면 단면과 실내 이동 공간도 검사해줘. 파일로 접근 가능한 결과와 생성용 지시·참조 목록은 outputs에 저장하고, 생성 후 실제 이미지를 열 수 있으면 검수 결과도 남겨줘. 구조 오류가 있으면 알아서 수정·재생성하고 실제 결과를 다시 검수해줘.

현재 v2.7/실행1.8에서는 단일 정사영·정사각 베이스·두 전면 평면 단면을 유지한다. 건물의 주된 배치와 직선 구조는 공통 X/Y축을 따르며 지상 곡면 외벽과 둥근 기계형 건축도 허용한다. 큰 형태·외벽 깊이·후퇴/돌출·계단·데크·지붕과 설비 결합으로 차이를 만들고, 임의 회전이나 좁은 쐐기 틈은 피한다. 기계는 특정 층 자체의 비거주 설비 부피가 될 수 있지만 모든 건물의2층에 강제하지 않는다. 건물 곡면 허용은 베이스의 둥근 테두리·모따기 허용이 아니다. 약11시/1시 방향의 기능 출구 두 개는 면 안 위치/형태가 자유이며 건물 입구 겸용·클리어 전 닫힘도 가능하다. 경계는 건물·설비·차량 등으로 연결하고 출구 상태와 개방 후 연결을 기록한다. 건물에만 입구·옥상40~80% 규칙을 적용하며 장면별 기계 비중과 구분한다. 콜리전·메시·UV 검증은 이미지 합격 조건이 아니며 보이는 접지·지지·연결·동선은 검사한다.

마스터03 본문 v2.2의 넓고 깨끗한 기본 색면과 일부의 크고 성긴 방향성 붓터치를 적용해줘. 가까운 톤의 평면 색 변화는 온전한 면에도 쓰며 손상과 구분해줘. M03-10 대표와 마스터27장은 유지하고, 별도 표면 보조4장 중 B03-01만 필요할 때 선택 입력해줘. B03-02~04는 표면 비교용으로만 읽고 기본·자동 생성 입력이나 기하 승인으로 취급하지 마. 상세 표현과 검수는 docs/03_VISUAL_STYLE_V2.md·docs/06_QA.md·docs/10_CURRENT_REFERENCES.md를 따라줘.

F-01~07은 큰 형태·외벽 깊이만 참고하는 선택 가능한 건축 형태 보강 자료이며 기본 입력은 아니다. F-08~11은 형태 선호 비교용으로만 사용하고 생성 입력이나 기하 승인으로 취급하지 않는다. 기존 마스터27장·표면 보조4장과 M03-10/M04-02 우선순위를 유지하며 F 예시의 기존 needs_revision 판정도 보존한다. 특정 L형·기계층·40%/20%·건물 수·소품·기후를 다음 장면의 기본값으로 고정하지 않는다.

실행 지시는 templates/generation_prompt.md의 구조→현재 장면→아트/참조 역할 순서로 압축하고 요구사항 대응표로 누락을 확인한다. 실제 최종 이미지의 같은 축 선군·상하 대응 모서리를 필수 정사영 기준으로 검수하며, 가려진 핵심 근거는 불확실로 남긴다. 도구 입력 길이/장수는 실제 전달값과 확인된 제한을 구분해 기록한다.
