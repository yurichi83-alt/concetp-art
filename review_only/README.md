# 검토 전용 — 기본 생성 참조로 전달하지 말 것

이 폴더는 과거 실패와 부분 승인 이력이다. 최신에 생성되었다고 마스터로 승격하지 않는다.

- `dense_pump_station.png`: 표면·부품·바닥 밀도가 지나치게 높은 사례. 사용자 스타일 비판의 비교 대상.
- `split_day_night_concept_only.png`: 사용자는 컨셉 방향·색감을 좋아했지만 01·02 누락을 지적했다. 분할 패널/풍경 크롭을 복사하지 않는다.
- `store_center_obstructed.png`: 중앙 진열대가 전투 공간과 충돌하는 사례. 패키지 작성 시 어시스턴트가 검토한 사례이며 사용자 승인/직접 평가로 오기하지 않는다.

기본 이미지 생성 입력으로 전송하지 않는다. 부분 수정/직접 비교 요청이 있을 때만 해당 역할을 명시해 사용한다.
