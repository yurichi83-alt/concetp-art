# Image review — masters v2.8 / execution v1.9

[06 QA](../docs/06_QA.md)의 정의로 실제 PNG를 검수한다. 조건별 상세 판정은 `requirements.json`의 `requirements[].observation` 한 곳에 작성한다. `checks[]`는 연결 요구행을 집계하고 근거 필드는 구체 요구행/아래 관찰 ID를 참조한다. 여기에는 실제 선쌍·확대·전후 비교처럼 원장의 짧은 행에 담기 어려운 근거만 적으며 별도 전체 판정표를 복사하지 않는다.

- 실제 image_path / native pixel size / sha256: 원장 candidate 참조
- 실제 열람 방법·시각 / 전체·확대 관찰 파일:
- 구조안/가이드 경로와 계획으로만 남는 내용:
- 검수 역할과 각자가 실제 본 원본/참조 (가능하면 아트 담당은 이전 PASS보다 참조·결과부터 관찰):
- 이전 재검토 기록 / 이번에 대체하는 판정 범위와 사유:

## 대표 선쌍 — 실제 이미지 관찰

원점은 원본 왼쪽 위, +x 오른쪽, +y 아래다. 축소 화면에서 읽었다면 원본 좌표 환산 방법과 수동 판독 불확실을 적는다. 숨은 선을 추정해 채우지 않는다. 모든 픽셀을 측정할 필요는 없지만 두 지면축·상하 베이스·각 건물의 관찰 가능한 높이를 대표해야 한다.

- 좌표 선택 방법 / 표시 배율 / 원본 환산 / 선택적 화면 각도 계산과 판독 오차:

| 근거 ID / 원장 ID | 같은3D 방향인 이유·선 종류 | 선A: 특징·원본 (x,y)→(x,y) | 선B: 특징·원본 (x,y)→(x,y) | 기대 관계와 실제 평행/수렴/크기 차이 | 한계·관찰 상태 |
|---|---|---|---|---|---|
| G01 / C02,C04 관련 행 | 베이스X 상단↔하단 | | | | NOT_REVIEWED |
| G02 / C02,C04 관련 행 | 베이스Y 상단↔하단 | | | | NOT_REVIEWED |
| G03 / C04 관련 행 | 베이스↔축방향 포장 | | | | NOT_REVIEWED |
| G04 / C04,L07 관련 행 | 베이스/포장↔건물 기단 (건물/축별 추가) | | | | NOT_REVIEWED |
| G05 / C04,L05 관련 행 | 기단↔상부 벽/수평 지붕 | | | | NOT_REVIEWED |
| G06 / C04 관련 행 | 바닥↔층바닥/셔터/테라스보/상층 | | | | NOT_REVIEWED |

수평 직선 모서리와 경사 지붕선·경사진 용마루/처마·차양·곡면 접선·그림자·회전한 비건물의 선을 먼저 분류한다. 공통 축 선군의 원근 수렴·거리별 크기 변화는 C04 FAIL이다. 건물 내부끼리 평행해도 지면과 비교한다. 임의 각도 임계값으로 통과시키거나 화면 각도를 실제3D 회전각이라고 주장하지 않는다.

가려진 핵심 기단/대응점은 UNCERTAIN이며 계획/AABB로 PASS를 대신하지 않는다. 바닥이 볼록한 인상, 외곽선의 실제 화면 굽음, 물리적3D 곡률 미확인은 구분한다. 실제 콜리전·메시·UV·미터 치수 검증은 이 이미지 작업의 합격 조건이 아니다.

## 표면·아트 독립 근거

전체에서는 큰 기능 부피/외벽 깊이/빛을, 확대에서는 아래 적용 표면을 각각 본다. 없는 표면은 이유를 연결한다. S03는 긍정 평면 붓터치 존재와 금지 질감 부재를 모두 확인한다. S02에서 소품 밀도를 표면 밀도로 대신하지 않는다. S04는 부피·깊이·두께·재질·빛·접지·기계 결합을 독립적으로 보며 C04 실패나 미검증3D를 복사하지 않는다.

| 표면/근거 ID / 원장 ID | 원본 영역·확대 파일 | 온전한 면의 큰 방향성 평면 터치·기본색 여백 | 자국 크기/방향/밀도·녹/박리와 구분 | 금지 잔선/물결 유사 얼룩/반복 균열·부조/모자이크 관찰 | 한계 |
|---|---|---|---|---|---|
| A-wall / 온전한 벽 | | | | | |
| A-machine / 기계 외장 | | | | | |
| A-vehicle / 차체 | | | | | |
| A-asphalt / 아스팔트 | | | | | |
| A-paving / 밝은 포장 | | | | | |

약간의 색 패치나 물/유리가 없다는 사실만으로 S03 PASS가 되지 않는다. 실제 셰이더·노멀맵 사용을 단정하지 않고 화면에서 읽히는 표현을 판정한다. 아트의 숫자 임계값이나 전역 붓질 비율을 새로 만들지 않는다.

## 장면 비교·수정 전후·선택

R02는 새 장소/독립 시안의 실제 큰 형태/외벽 깊이/배치·경계·출구/포장·단면 차이, R03은 같은 시안 수정 전후 보존이다. 적용 대상·이미지·해시·관찰은 원장의 `comparison` 및 `selection.considered_candidates`에 작성한다. 여기에는 추가 확대/도해가 필요한 비교 근거만 연결한다.

- 실제 비교 대상·동일 역할 영역·추가 근거 ID:
- 명시 변경 목표 / 보존 대상인 큰 하우징·리세스·굵은 프레임·날개/후퇴 등의 구체 이름:
- 원장 7차원(구조/큰 형태/외벽 깊이/표면/빛·재질/세계관/요청)의 추가 관찰·잔여 후퇴:

기계층/곡면/층수 유무만으로 보존을 판정하지 않는다. 앞선 오류와 명시 변경 대상을 유효한 보존 조건에서 구분한다. 기존 붓질 미달이 그대로인 것은 후퇴 없음일 수 있으나 S01/S03 PASS는 아니다. 한 차원의 개선으로 다른 필수 요건 후퇴를 상쇄하지 않으며 최신본을 자동 선택하지 않는다.

## 기록 검증·후속 조치

```sh
python3 scripts/validate_run.py --run outputs/<run> --stage review
python3 scripts/validate_run.py --run outputs/<run> --stage selection
```

- 검증 결과/파일 / 미해결 원장 ID:
- 관찰 실패의 다음 보정 목표·변경 요인·보존 조건 또는05의 중단 사유:

원장 candidate/result/final_manifest의 상태·해시·선택 사유를 일치시킨다. 모든 적용 C/L/S/W/R이 PASS/근거 N/A일 때만 candidate_pass, 어떤 FAIL도 needs_revision, 불확실은 uncertain, 미관찰은 not_reviewed다. RECORD PASS는 연결 일관성이며 실제 형태·붓질의 충족이나 가짜 관찰 부재를 자동 보증하지 않는다.

승인 `master_update_20260912_v2_8_pipeline_quality`에 따라 생성/편집 요청의 명시 요건 FAIL을 보정·재검수한다. 참조 역할을 보존하고 아트/세계관 일괄 제거를 기본 기하 보정법으로 삼지 않는다. 분석/검수/마스터 갱신만 요청하면 생성하지 않는다. 미달 전달에는 원장의 한계·후퇴·중단 사유를 밝히며 final 보관을 합격/승격과 구분한다. 원본·이전 검수는 보존한다.
