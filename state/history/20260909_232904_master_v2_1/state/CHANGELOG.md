# 기준 변경 이력

## 2026-09-09 — 패키지 1.0.0
- 사용자가 정한 마스터 01~04 v2와 생성 실행 규칙 v1을 파일로 이식.
- 03: 큰 색면·선택적 손상·표면/부품/배치 밀도 제어 보강 내용 포함.
- 04: 회수·수리·개조의 의미를 유지하되 03보다 사실적 표면이 우선하지 않도록 분리.
- 중앙 전투 공간 개방과 출구 접근로·외곽 배치 조건 포함.
- 01·02 누락 방지를 위해 도해 원본과 실제 참조 전달 상태를 기록하도록 구성.
- 원본 19장과 검토용 생성물 3장을 분리. 후자는 양성 스타일 마스터가 아님.
- 사용자 의도에 맞춰 짧은 요청 → 생성 경로 사용. 별도 앱 제작·전역 설정·API 과금 자동화 없음.
- 사용자 Codex에서의 이미지 생성 시험은 아직 수행하지 않음.

이후 변경은 사용자 명시 요청, 적용 범위(이번 장면/기본값), 변경 문서를 기록한다.

## 2026-09-09 — 사용자 시각 기준 교체
- A-01 야간 광장 / A-02 주간 골목을 현재 기준으로 승인. 기존 22장과 이전 outputs는 테스트 이력.
- 기본 참조·03 표현 지침·생성 규칙·QA를 새 방향으로 교체. 명시적 공간 조건 유지.
- 이미지 생성 없이 문서/참조만 변경.

## 2026-09-09 — 아트 표현/세계관 역할 정정
- 참조 교체를 Little Devil Inside 아트 방향 폐기로 넓게 해석한 어시스턴트 변경을 정정.
- 건축 형태·맵핑 텍스처 묘사·라이팅·색감은 Little Devil Inside, 해당 게임 세계관 제외. 세계관은 Salvage Cyberpunk.
- A-01/A-02는 원하는 결과의 이미지 기준으로 유지. 기존 파일 입력 재활성화나 이미지 생성은 하지 않음.

## 2026-09-09 — 원본 마스터 위계 복원 (앞선 교체 해석 철회)
- 원본 마스터 19장 활성 복원. 01~04 v2 기본 문서 복원 및 역할 명시.
- Little Devil Inside 아트 표현(세계관 제외)·Salvage Cyberpunk 세계관 고정.
- A-01/A-02는 원본 기준에서 생성된 선호 결과 예시 2장으로 별도 분류. 기존 원본 제외라는 어시스턴트 해석은 철회.

## 2026-09-09 — 테스트 결과의 마스터 갱신 절차 명시
- 사용자가 테스트·수정 결과를 명시적으로 추가/갱신 요청하면 승인 범위만 마스터에 반영하고 이후 생성에 적용.
- 시안 한정 수정·단순 선호·영구 갱신을 구분하며 이전 원본과 변경 이력 보존.
- 절차만 기록. 이번에 새로 승격하거나 교체한 이미지 없음.
