# Game Environment Art

이 스킬은 로컬 아트 기준을 실제 이미지 생성 도구에 적용하는 지침이다. 독립 이미지 엔진이나 API 클라이언트가 아니다.

## Locate and read
이 파일에서 위로 찾아 AGENTS.md·project.json이 있는 프로젝트 루트를 확인한다.
루트의 docs/10_CURRENT_REFERENCES.md에서 원본 마스터와 선호 결과의 위계를 확인하고, docs/00_INDEX.md와 상세 마스터 01~04, docs/05_GENERATION_RULES.md 및 docs/06_QA.md를 읽는다.
각 요청 직전 실행 규칙·현재 사용자 요청·refs/manifest.json·명시적 승인 상태를 확인한다.
최신 문서 변경을 반영하되 출력 시안마다 전체 기준을 사용자에게 재설명하지 않는다.

## Act on short commands
1. docs/08_COMMANDS.md에 따라 새 장소와 기존 이미지 편집을 구분한다. 새 장소는 현재 기능에 맞는 건축·배치·포장·단면을 설계하고 이전 장면의 소품/날씨를 자동 계승하지 않는다. 기존 마스터의 공간 조건은 유지한다.
2. 현재 세션의 실제 내장 생성 도구/공식 imagegen 스킬 설명을 확인한다. 존재하지 않는 도구를 호출하지 않는다.
3. 원본19장+LDI 보강5장(총24장)의 역할을 확인한다. 새 장소에는 M02-01/M01-01 공간, M03 건축 표현, M04 세계관 형태가 균형 있게 포함되도록 05의 입력 선택 절차를 따른다. 선택한 이미지는 실제로 열어 보고 도구 입력으로 전달한다. M03-10은 대표 원본, M03-11~15는 승인된 보강 자료다. A-01/A-02 및 부분 선호 출력은 마스터를 대체하지 않는다.
4. 같은 XYZ/척도와 하나의 투영으로 기본 블록·경계/출구·건물 부피·보행 보호 공간의 구조안을 먼저 만든다. templates에 따라 구조안·브리프·참조 전달·사전 점검을 outputs에 기록한다.
5. 준비되면 불필요한 추가 동의 없이 요청 장수를 최종 목표로 실제 생성한다. API·설치·권한 확대가 필요하면 먼저 알린다.
6. 실제 결과를 저장하고 열어 구조안과 대조한다. 기본 입체→공통 투영→접지/경계→두 외부 통로→해당 내부 동선→아트/세계관/키워드 순서로 검수한다. 새 장소가 시간/색만 바뀐 이전 설계인지도 확인한다. 불가능하면 미검수 상태를 기록한다.
7. 생성/편집 요청의 실제 검수에서 C01~C04·L01~L07 구조 오류가 있으면 docs/05_GENERATION_RULES.md에 따라 사용자 재확인 없이 수정·재생성하고 재검수한다. 모든 적용 구조 항목이 통과하면 중단한다. 미관 취향만으로 추가 변형을 만들거나 자체 QA로 아트 마스터를 승인하지 않는다.

## 고정 아트/세계관
Little Devil Inside의 건축 형태·맵핑 텍스처 묘사·라이팅·색감을 참고하되 해당 게임 세계관은 제외한다. 세계관은 Salvage Cyberpunk. 낡은 건물·기반 시설·생활 설비에서 기능적인 회수·수리 기술이 읽히게 하되 넓고 정돈된 표면을 유지한다. 깨끗한 표현을 새것으로, 노후함을 전면 미세 오염으로 해석하지 않는다. 두 방향은 선호 이미지 첨부로 변경하지 않는다.
추가 LDI5장은 건축·재질·조명/색만 사용한다. M03-12는 건물 부분만 사용하고 나무·풀·숲·자연 지면 제외. 이 범위를 프로젝트 전체 식생 금지로 확대하지 않는다.
기계 비중과 단면의 부분 선호는 지정 속성의 비교 기준이며 정량비율·동일 장치/배관 복제·전체 생성물 승격이 아니다. 상세 승인 범위는 docs/10_CURRENT_REFERENCES.md.
향후 3면도/AI 모델링을 위해 부피·두께·접지·결합이 읽히게 한다. 실제 UV/맵/3면 정합은 별도 작업이다.

## Required output intent
단독 쿼터뷰 디오라마 / 베이스 전체 / 노출된 단면 / 뒤쪽 두 방향에 기능 출구 하나씩(면 안의 위치·형태 가변, 건물 입구 겸용·클리어 전 잠금 허용) /
중앙 전투 바닥과 접근로 개방 / 큰 물체 외곽 / 03의 큰 색면과 선택적 디테일 / 04의 수리·개조 첨단기술.

## Host compatibility
상위 시스템과 도구 계약이 우선한다. 생성 도구가 대화의 지시를 직접 사용하는 경우 그 도구의 입력 방식대로 실행한다.
부가 문서나 파일 경로만으로 이미지 참조가 자동 첨부된다고 가정하지 않는다.
생성 후 즉시 종료해야 하는 호스트에서는 후속 저장/QA를 다음 턴으로 미룬다. 보지 못한 결과는 PASS로 기록하지 않는다.
이미지 생성이 불가능하면 막힌 단계를 정확히 보고한다. 앱을 만드는 것으로 요청을 바꾸지 않는다.

## v2.3 필수 구조 규칙
정육면체형 공통 공간·정사각형 기본 평면·하나의 카메라/투영 및 상하 대응 모서리를 유지한다. 통로는 가는 빈 선이 아닌 보행 폭/높이/회전 여유로 검사한다. 외곽 잔해/상자/장치 부피도 포함한다.
C01~C04·L01~L07에서 FAIL 하나라도 있으면 needs_revision, 핵심 불확실은 uncertain이다. 전체 입체/원근 오류는 잘못된 기하를 보존하는 편집 대신 01·02에서 재구성한다. 분석/검수/마스터 갱신만 요청된 경우 자동 생성하지 않는다. 시각적 오류를 3D 치수 미검증으로 면제하지 않는다.

## v2.3 실행 보완
건물 지상 외곽선/접촉 외벽은 공통 X/Y축 직교로 계획하고 L07로 검사한다. 단일 상자 대신 L/T/U형·직각 후퇴·높이와 지붕 변화로 다양화한다. 소품·원통 탱크·차량의 곡면/회전은 이 제한 밖이며 벽 역할도 가능하다. 건물용 입구·옥상40~80%를 비건물에 적용하지 않는다.
두 출구는 약11시/1시 방향에 하나씩, 각 면의 중앙/중간/끝 모두 가능하다. 문틀/열린 게이트로 고정하지 않으며 건물 진입·골목·계단·지하주차장 램프도 허용한다. 역할/위치/형태/개폐 상태/클리어 후 연결/건물 입구 겸용을 기록한다. 잠금 상태와 잔해 차단은 구분하고 개방 시 문짝 및 경로 여유를 검토한다.
도해/직전 구조안의 끝쪽 출구 좌표를 자동 복제하지 않는다. 지붕 경사·벽 상단·설비 지지의 정합은 최종 이미지에서 따로 확인하고 불확실한 면을 의도적 형태로 합격시키지 않는다. 승인 master_update_20260910_v2_3; 실행 v1.4.
