# 결과 검수와 승인

> 기준 관계: 마스터 01~04 v2.3와 원본 19장+승인된 LDI 보강 5장(총24장)이 기준이다. Little Devil Inside 아트 표현(세계관 제외)과 Salvage Cyberpunk 세계관은 고정한다. A-01/A-02는 선호 예시이며 마스터를 대체하지 않는다. 상세: `docs/10_CURRENT_REFERENCES.md`.

원본 마스터 적합성을 먼저 검수하고 A-01/A-02의 선호 결과 인상도 함께 비교한다. 선호 예시를 원본 마스터의 대체 기준으로 삼지 않으며, 디테일 개수만으로 기계적으로 판정하지 않는다.

## 검사 순서
기본 입체 → 공통 투영/지붕 면 정합 → 건물 직교 경계 → 바닥/경계 접합 → 두 기능 출구의 상태별 동선 → 해당 내부 동선 → 스타일 → 세계관 → 개별 요청.
실제 이미지에서 관찰한 근거를 기록한다. 프롬프트에 들어 있으므로 PASS라고 판단하지 않는다.
이미지를 열 수 없으면 `NOT_REVIEWED`; 애매하면 `UNCERTAIN`으로 남긴다.

S01은 넓은 면의 정돈 여부를 보고 건물의 신품 여부와 분리한다. W02는 큰 파손·보수·교체·우회 공급 등 실제 환경의 흔적으로 확인한다. W03은 승인된 낮 골목 보강 시안의 기계 비중을 필요한 경우 비교하되 수치 비율이나 장치 복제를 요구하지 않는다. R02는 새 장소 요청에 적용하고 기존 장면의 명시적 편집에는 NOT_APPLICABLE로 기록한다. 개별 변경 개수를 강제하지 않고 장소로서의 차이를 근거로 판단한다.

고저차·계단·램프·경사지붕은 연결·접지와 건물의 직교 보행 경계를 지키면 허용한다. 계단/램프의 평면 진행 방향과 건물 경계도 X/Y축을 따른다. L/T/U형, 직각 후퇴/돌출, 높이와 지붕 변화로 다양화하며 원본02를 동일 건물 두 줄이나 단일 높이로 축소하지 않는다. 소품·차량·원통 탱크의 곡면/회전은 L07 제한 대상이 아니지만 공통 투영·접지·차단 역할·통로 보존은 검사한다. 건물이 없는 장면은 L07에 N/A 근거를 남긴다.

출구 위치는 각 면의 중앙·중간·끝 모두 가능하며 고정 좌표나 강제 교대 순서가 아니다. 건물 입구/내부 전환, 건물 사이 골목과 개폐 철문, 계단/시설 통로, 지하 주차장 램프 등의 기능을 판정한다. 모든 출구에 독립 문틀과 문턱 너머의 노출 바닥을 요구하지 않는다. 닫힌 출구는 접근 공간·개방 장치의 여유·클리어 후 연결 계획을 확인하고, 열린 출구는 실제 보이는 연결 동선의 장애물을 확인한다. 전환 대상인 건물 내부 전체가 숨겨졌다는 이유만으로 실패시키지는 않되 입구 규모/접근/기능이 모호하면 UNCERTAIN이다. 지정 후방 출구의 지하 진입과 전면 토층 절개의 제3출구화를 구분한다.

높이 약 6.5m, 정확한 통로 폭, 실제 플레이어/콜라이더 통과는 3D 치수 검사 대상이다.
이미지 검수에서 수치 적합으로 단정하지 않는다. S04도 3면도 정합·AI 메시 품질·UV/재질맵 검증을 뜻하지 않는다. 계획 의도와 확실히 과도한 높이 여부만 기록한다.
출구 수는 문 개수가 아닌 지정 이동 기능으로 세며, 계획과 실제 관찰을 구분한다. 가려지거나 기능이 애매하면 정확히 두 개라고 확정하지 않는다. 닫힌 상태의 개방 후 동작을 한 장의 이미지로 실증했다고 주장하지 않는다.

## v2.3 필수 구조 판정
검사 순서는 기본 입체 → 공통 투영/지붕 면 정합 → 건물 직교 경계 → 바닥/경계 연결 → 두 기능 출구의 상태별 동선 → 해당 내부 동선 → 아트/세계관/요청 사항이다. C01~C04·L01~L07 중 하나라도 FAIL이면 전체 결과는 needs_revision이고, 핵심을 확인할 수 없으면 uncertain이다. 분위기·소품·세계관이 잘 나와도 구조 실패를 상쇄하지 못한다. 베이스나 공통 원근이 잘못되면 실패 이미지의 기하를 보존하는 편집을 중단하고 원본01·02의 공간 틀로 재구성한다. 사용자 요청이 분석/검토/마스터 갱신인 경우에는 자동 재생성하지 않는다.

- C01 프레이밍은 C03 기본 기하/C04 투영을 대신하지 않는다. C02도 흙/배관의 존재만으로 통과하지 않는다.
- C04/L05는 지붕 면의 경사 시작/끝·용마루/골/처마·벽 상단·장비 받침의 연결을 따로 기록한다. 구조가 읽히지 않으면 UNCERTAIN, 명백히 꼬이거나 지지가 모순이면 FAIL이다. 의도된 비정형이라는 설명은 통과 근거가 아니다.
- L02/L03은 좌/우 각각 면 안 위치·형태·현재 개폐 상태·클리어 후 연결·건물 입구 겸용, 시작부·최소 폭·회전부·전환부·개방 여유를 기록한다. 열린 상태의 보이는 연결과 닫힌 상태의 계획된 연결을 구분하고 물체의 부피 침범을 검사한다.
- L06은 해당 실내를 보이는 경우 적용하고 미해당은 N/A 근거를 기록한다.
- L07은 구조안의 건물 수평 외곽선/각 선분 축과 최종 이미지의 실제 접촉 경계를 대조한다. 화면 픽셀 각도가 아니라 공통 공간 축을 기준으로 판단하며, 경계상자(AABB) 비충돌만으로 통과시키지 않는다.
- 모든 적용 구조 항목이 PASS여야 통과한다. 구조 FAIL 하나는 전체 needs_revision이며 핵심 불확실은 uncertain이다.
- 정투영의 평행선과 투시의 방향별 소실점/공통 지평선을 구분한다. 허용된 소품/비건물 회전도 같은 카메라를 따라야 하며 건물 회전은 L07을 따른다.
- 3D 치수/콜라이더 미검증은 눈에 보이는 차단/비틀림의 면제 사유가 아니다.

## 상태
- `candidate_pass`: 관찰 가능한 필수 기준에서 문제가 발견되지 않은 후보. 사용자 승인 아님.
- `needs_revision`: 기준 누락/실패 있음.
- `uncertain`: 핵심이 가려져 판단 어려움.
- `not_reviewed`: 실제 결과를 보지 못했음.
- `user_approved`: 사용자가 승인한 범위를 별도로 명시했을 때만.

## 실패에 따른 대응
구도/단면이 완전히 틀리면 실패 이미지 보존 편집에 집착하지 말고 01·02를 기반으로 재구성한다.
공간은 맞고 표면만 과밀하면 구도를 유지하며 밀도를 수정한다.
출구 한 곳만 누락됐으면 주변 경계만 수정하고 다른 공간/스타일의 변형 여부를 다시 본다.
구조 오류(C01~C04, L01~L07)는 사용자 상시 승인과 master_update_20260910_v2_3의 검사 구체화/L07 반영에 따라 수정·재생성하고 실제 이미지로 재검수한다. 최종 전달 장수는 유지한다. 구조 통과 후 중단하며 도구 장애/관찰 불가/진전 없는 반복의 중단 기준은 docs/05_GENERATION_RULES.md를 따른다. 스타일 취향만으로 추가 변형을 만들지 않는다. 분석/검토/마스터 갱신 요청에서는 이미지 생성이 시작되지 않는다.

## 승인 기록
`state/approvals.json`에 사용자 발언과 승인 범위를 함께 남긴다.
“색감 마음에 들어”는 color 승인일 뿐 layout/material/overall 승인이 아니다.
`review_only/`는 실패/부분 승인 이력이다. Codex 자체 QA로 원본 마스터를 교체하지 않는다.

사용자가 테스트 결과의 마스터 추가·갱신을 명시하면 `docs/10_CURRENT_REFERENCES.md`의 절차로 승인한 범위만 반영한다. QA 통과나 단순 선호와 영구 기준 갱신을 구분한다. 명확한 갱신 요청에 불필요한 재확인을 요구하지 않는다.

건물별로 근거를 기록하며 전체 평균으로 처리하지 않는다. W05 면적은 마스터04의 평면 점유 기준으로 계획하고 최종2D는 관찰 추정/불확실을 구분한다. 전체 기계화율이 아니며 그림자/때/평판 표면은 채움에 포함하지 않는다. 건물로 설계한 대상에만 W04/W05를 적용하고 비건물에는 기능에 맞는 구조·접지·연결을 검사한다. 건물이 없으면 N/A 근거를 남긴다.
W04/W05는 외관 디자인 검사다. 각 건물 입구는 장식 / 좌측 기능 출구 겸용 / 우측 기능 출구 겸용으로 기록한다. 겸용이면 같은 방향에 별도 출구가 필요하지 않으며, 별도 출구가 있다면 나머지 문은 장식이다. W04만으로 실제 게임플레이 진입을 요구하지 않으며, 겸용 입구의 출구 기능은 L02/L03으로 판정한다. 명백한 FAIL은 전체 needs_revision, 핵심 불확실은 uncertain. 기존 결과의 과거 검수는 새 규칙으로 소급 덮어쓰지 말고 새 검토 기록을 남긴다. 외관 검사 자체가 C01~C04/L01~L07의 구조 자동 보정 권한을 확대하지 않는다.
