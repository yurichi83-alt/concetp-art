## v2.1에서 유지하는 공통 원칙

1. 표면 묘사는 넓고 정돈된 면으로, 낡음은 선택적인 큰 파손·보수·바랜 색면으로 표현한다. 깨끗함을 신품 상태로 해석하지 않는다.
2. 장소 키워드와 무관하게 Salvage Cyberpunk를 기본 적용한다. 건물·기반 시설·생활 설비 전반에서 쇠락과 고쳐 쓰는 이유가 읽혀야 한다.
3. 건물과 일상 설비에도 기능적인 회수 기술을 통합한다. 작은 부품·표시등을 늘리는 것만으로 기술을 설명하지 않는다.
4. 승인된 기계 비중은 건축 대비 시각적 존재감의 비교 기준이다. 정량 비율, 기계 수, 모든 사물의 기계화, 장치 복제는 고정하지 않는다.
5. 새 장소는 건축 용도·매스·폭·배치·포장·설비로 구분한다. 시간과 색만 바꾸어 이전 장소를 반복하지 않는다.
6. 단면의 두께와 기계 기반 시설 표현은 유지하면서 지상 기능에 맞는 내부 설계를 새로 정한다.
7. 빛과 밀도는 형태를 읽게 하고 현재 장면 요청에 따른다. 밤·젖은 바닥·안개·쓰레기·전봇대 등은 자동 누적하지 않는다.
8. 향후 3면도/AI 모델링에 이어질 부피·두께·접지·결합 가독성을 확보한다. 실제 3면 정합·UV·맵·셰이더 제작법은 별도 작업이다.

상세 기준은 01~04, 키워드 해석은 08, 관찰 항목은 06을 따른다.

## 최신 건축 외관 추가 — 2026-09-10

사용자가 메인 레퍼런스 추가 내용으로 직접 지정한 architecture_entrances_roofs_20260910를 마스터v2.2에 반영했다.

1. 각 건물에는 사람이 출입할 수 있다고 납득되는 문·셔터·출입구 중 최소 하나를 외관에서 식별 가능하게 설계한다. 실제 게임플레이 진입, 열린 문, 내부 구현을 의무화하지 않으며 닫힌 문이나 내려진 셔터도 가능하다. 사람 크기의 비례, 문틀·문턱·손잡이/셔터 구조 및 바닥과의 연결로 출입 용도가 읽혀야 한다. 작은 점검 패널, 환기구, 창문을 출입구 대신 세지 않는다.
2. 건물 윗면이 넓고 밋밋하게 남지 않도록 각 건물의 옥상/지붕 윗면 40~80%를 설득력 있는 설비·기계·소품 또는 기능적 건축 요소로 구성한다. 건물마다 용도에 맞는 전력·환기·물 저장·통신·보관·차양 등에서 선택하고, 받침/고정·공급 연결·필요한 유지 접근이 납득되게 배치한다. 모든 지붕에 같은 장비를 반복하거나 면적을 채우려고 미세 부품을 흩뿌리지 않는다.

출입구 디자인과 기능 출구는 역할로 구분하며 물리적 분리 의무가 아니다. 건물 문/셔터를 지정된 두 출구 중 하나로 겸용할 수 있다. 나머지는 장식 입구이며 문의 개수로 기능 출구 수를 늘리지 않는다. 옥상 요소는 공통 투영·납득되는 지지·기존 높이/전체 프레이밍과 두 출구/중앙 시야를 유지해야 한다. 넓은 색면과 선택적 디테일이라는 마스터03 표현도 유지한다.
