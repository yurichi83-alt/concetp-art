# Codex에서 처음 시작하기

> 기준 관계: 마스터 01~04 v2.5와 원본 19장+승인된 LDI 보강 5장+사용자 추가 2장(총26장)이 기준이다. Little Devil Inside 아트 표현(세계관 제외)과 Salvage Cyberpunk 세계관은 고정한다. A-01/A-02는 선호 예시이며 마스터를 대체하지 않는다. 상세: `docs/10_CURRENT_REFERENCES.md`.

이것은 **이미지 생성 프로젝트의 작업 폴더**입니다. Unity 프로젝트, 웹앱, API 서버, 자체 이미지 생성기는 아닙니다.

## 사용 순서
1. ZIP을 풀고 `GameConcept_Codex` 폴더를 원하는 위치에 둡니다.
2. Codex의 로컬 작업 폴더/프로젝트로 **이 폴더 자체**를 엽니다. ZIP 파일이나 AGENTS.md 한 장만 첨부하는 방식과 다릅니다.
3. 아래 첫 요청을 한 번 입력합니다. 마스터 참조는 원본19장+LDI 보강5장+사용자 추가2장으로 총26장 들어 있으므로 다시 첨부할 필요 없이 경로를 확인하도록 합니다.
4. 이후 같은 프로젝트에서는 `교역장 / 밤 / 드럼통 / 한 장`처럼 달라지는 키워드만 입력합니다.

## 처음 한 번 붙여넣을 요청
```text
이 폴더를 내 게임 배경 컨셉아트 작업 프로젝트로 사용해줘. 새 웹앱이나 이미지 생성 프로그램을 개발하는 요청은 아니야.

AGENTS.md와 START_HERE_KO.md를 읽고, 마스터 01~04 v2.5·생성 실행 규칙·원본 레퍼런스 경로를 확인해줘. scripts/validate_project.py로 파일 누락도 확인해줘.
이후에는 내가 “장소 / 시간대 / 소재 / 한 장”만 입력해도 기존 공간과 스타일 규칙을 유지해서 바로 이미지를 생성해줘.

현재 환경의 내장 이미지 생성 기능과 imagegen 스킬 사용 가능 여부를 먼저 확인해줘. 사용 가능하면 그 기능을 사용하고, 별도 과금 API나 추가 설치가 필요하면 실행 전에 알려줘. 전역 설정은 바꾸지 마.

준비가 되면 별도 재확인 없이 첫 테스트를 진행해줘:
교역장 / 밤 / 드럼통 / 한 장

정육면체형 공통 공간과 필수 정사영으로 구조안을 먼저 잡고, 중앙부터 두 출구 너머까지 물체가 침범하지 않는 보행 공간을 확보해줘. 베이스 상하 대응/평면 단면과 실내 이동 공간도 검사해줘. 파일로 접근 가능한 결과와 생성용 지시·참조 목록은 outputs에 저장하고, 생성 후 실제 이미지를 열 수 있으면 검수 결과도 남겨줘. 구조 오류가 있으면 알아서 수정·재생성하고 실제 결과를 다시 검수해줘.
```

## 요청 예시
- `도심 골목 / 낮 / 폐건물과 쓰레기통 / 좁은 공간 / 한 장`
- `항만 하역장 / 쿨톤 밤 / 얕은 물웅덩이 / 한 장`
- `실내 마트 / 어두운 쿨톤 / 형광등과 진열대 조명 / 한 장`
- `검수만 해줘` — 기존 결과를 검사하며 새 이미지를 생성하지 않습니다.
- `방금 이미지의 구도와 색감은 유지하고 표면 디테일만 줄여줘` — 변경 범위를 한정합니다.

마트도 기본적으로 중앙 진열대를 두지 않고 외곽 진열대를 사용합니다. 좁은 골목은 공통 공간 틀 안의 배치를 조정하되 중앙과 출구의 보행 공간을 막지 않습니다.

## 알아둘 점
- 현재 계정/클라이언트의 내장 생성 기능을 먼저 확인하도록 되어 있습니다. 별도 API 키·API 과금은 자동 설정하지 않습니다.
- `.agents/skills/game-env-art/`는 프로젝트 규칙을 적용하는 로컬 지침 스킬입니다. 이미지 모델이나 생성 엔진을 설치하는 파일이 아닙니다.
- 요청 장수는 최종 전달 장수입니다. 출구·배치·지면·동선·프레이밍 등 구조 오류는 실제 검수 후 자동 수정·재생성합니다. 구조가 맞으면 중단하며, 미관 취향만으로 추가 변형하지 않습니다.
- 현재 환경에서 생성 뒤 파일 접근/후처리가 불가능하면 검수는 `not_reviewed`로 남기거나 다음 턴에 진행합니다. 검수한 척하지 않습니다.
- 한 장의 출구 개수·구도 재현을 100% 보장하는 패키지는 아닙니다. 지시 누락과 결과 오류를 추적하는 운영 구조입니다.
- 이 프로젝트의 이전 생성·검수 기록은 outputs에 있습니다. 현재 세션의 생성 도구 제공 여부는 작업 때 확인합니다.

자세한 기능/초기 진단: `docs/07_CODEX_SETUP.md`.
원본 이미지 확인: `REFERENCE_INDEX.html`을 브라우저로 열 수 있습니다.

현재 v2.5/실행1.6에서는 모든 최종 이미지에 단일 정사영을 적용한다. 건물 지상 경계를 X/Y축 직교로 설계하고 지붕·높이·직교 매스로 다양화한다. 탱크·차량도 뒤쪽 경계 역할이 가능하다. 약11시/1시 방향의 기능 출구 두 개는 면 안 위치/형태가 자유이며 건물 입구 겸용·클리어 전 닫힘도 가능하다. 출구의 상태와 개방 후 연결을 기록하고, 이전 끝쪽 게이트 배치를 고정하지 않는다. 건물 입구·옥상40~80% 규칙은 건물에만 적용한다.

실행 지시는 templates/generation_prompt.md의 구조→현재 장면→아트/참조 역할 순서로 압축하고 요구사항 대응표로 누락을 확인한다. 실제 최종 이미지의 같은 축 선군·상하 대응 모서리를 필수 정사영 기준으로 검수하며, 가려진 핵심 근거는 불확실로 남긴다. 도구 입력 길이/장수는 실제 전달값과 확인된 제한을 구분해 기록한다.
