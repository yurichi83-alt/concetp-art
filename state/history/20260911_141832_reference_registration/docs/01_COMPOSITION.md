## 유지할 것
- 작은 세계를 사선 위에서 내려다보는 쿼터뷰. 완전 탑다운·아이레벨·일반 풍경 파노라마가 아니다.
- 정사각형 기본 평면의 독립형 디오라마 베이스와 연결된 경계 전체를 프레임 안에 담는다. 기본 외형 변경은 사용자 명시 요청으로만 적용한다. 특히 앞쪽 모서리와 두 측면을 자르지 않는다.
- 바닥은 얇은 판이 아니라 두께 있는 블록이다. 카메라를 향한 두 측면에 내부 단면을 노출한다.
- 흙/지층·기초·배수/설비 배관을 장소에 맞게 일부 보여준다. 전면 절개 단면을 지하 보행 통로나 제3의 출구로 만들지 않는다. 뒤쪽 지정된 두 기능 출구 중 하나를 지하 주차장 램프/계단으로 설계하는 것은 가능하다.
- 지하 단면은 03 v2.1에 맞춰 큰 지층 덩어리와 기능이 읽히는 굵은 설비 형태로 단순화한다.
- 배경은 베이스의 독립성이 읽히게 절제한다. 먼 도시/바다가 필요한 경우에도 베이스와 카메라를 희생하지 않는다.
- 디오라마는 **공간 제시 방식**이다. 정밀 모형 사진의 입자감·피사계심도·초세밀 표면을 따라하지 않는다.

## 장소별 구도와 단면 설계
전체 쿼터뷰·베이스·양면 단면은 공통 조건이며, 직전 이미지의 건물 윤곽이나 단면 배관 배치를 고정하는 조건이 아니다.
새 장소에서는 공통 공간 틀 안에서 건축 용도·매스·내부 공간 폭·포장·외곽 기반 시설을 새로 설계한다. 배치 변화가 기본 입체의 휨이나 임의 외형 변경을 허용하지 않는다.
같은 상자형 두 건물이나 같은 크기의 문틀을 반복해야 할 이유는 없다. 출구와 경계의 연결 관계는 02를 따른다.

사용자가 선호한 단면의 기계적 기반 시설 표현은 유지한다. 지층·기초·배수·전력·설비의 큰 형태와 절제된 재질 묘사를 참고하되,
같은 굵은 배관·보강판을 복제하지 않는다. 지상의 건물 용도와 생활·작업 설비에 맞춰 지하 기능과 연결 이유가 읽히도록 구성한다.
단면을 채우기 위한 무의미한 기계 증식이나 미세 부품 나열을 피한다.

## 실내
전면 벽과 천장을 시야에서 절개/생략하여 방 안이 보이게 한다. 베이스와 바닥 하부 단면은 그대로 유지한다.
온전한 천장, 전면 높은 벽, 크레인 등이 중앙이나 두 출구를 가리게 하지 않는다.

## 미정
정확한 정투영 카메라 수치, 회전각·틸트 각, 베이스 폭/깊이/단면 두께는 아직 승인되지 않았다.
투영 방식은 아래와 같이 정사영으로 확정한다. 회전각·틸트·정사영 배율은 장면별로 선택하며 특정 아이소메트릭 각도(예: 30°)나 새 치수를 영구 기준으로 고정하지 않는다.

## v2.2 공통 공간 틀
모든 장면은 하나의 정육면체형 가상 공간 안에 건물·소품·자연물을 배치한 독립형 디오라마로 설계한다. 기본은 정사각형 평면과 서로 직교하는 X/Y/Z 축이다. 바닥·뒤쪽 두 경계·건물·외벽·소품은 동일한 공간과 척도 안에 놓인다. 정육면체는 공간 구성의 기준 틀이며, 화면에 유리 상자나 여섯 개의 닫힌 벽을 그리라는 뜻이 아니다. 하부 단면 블록의 두께가 베이스 폭과 같아야 한다는 뜻도 아니다. 기본 외형의 변경은 사용자 명시 요청이 있을 때만 적용한다.

## 공통 카메라와 투영 — v2.5
승인: master_update_20260911_v2_5 (2026-09-11). **최종 이미지는 반드시 오소그래픽(orthographic, 정사영/직교 평행투영)으로 제작한다.** 기존의 약한 투시 선택 허용은 폐지한다. 하나의 정사영 카메라를 구조안·브리프·실제 생성 지시에 명시하고, 베이스 상·하단, 포장, 건물 기단·외벽·지붕, 경계·출구, 소품·차량·자연물까지 동일하게 적용한다. 원근에 따른 선 수렴·크기 변화나 물체별 카메라 혼용은 허용하지 않는다. 참조 원본의 카메라보다 이 규칙이 우선한다.

- 정투영/평행투영: 같은 3D 방향에 속하는 수평 선분은 높이·위치가 달라도 화면에서 평행하다. 베이스의 X/Y 상단과 하단, 축을 따르는 포장선, 건물 기단·벽 상단과 해당 방향의 수평 지붕선을 비교한다. 같은 깊이로 내린 베이스의 상하 대응점은 같은 화면 수직축 방향과 길이의 벡터로 연결된다.
- 동일한 실제 길이와 3D 방향의 선분은 깊이가 달라도 화면 길이가 같다. 거리 때문에 가까운 부분만 확대하거나 먼 부분만 축소하지 않는다. 회전·경사 때문에 실제 방향이 다른 선분의 화면 길이까지 같게 만들라는 뜻은 아니다.

쿼터뷰에서 바닥 방향이 화면 사선으로 보이는 것은 정상이다. 그 방향은 같은 축의 건물 기단·벽 상단에도 이어져야 한다. 건물 지상 평면과 플레이어 접촉 외벽은 공통 X/Y축의 직교 형태로 제한한다. 회전한 소품·차량·비건물은 고유 방향을 가질 수 있으나 같은 카메라를 따른다.

비교할 선은 먼저 실제 방향과 기능을 분류한다. 경사 지붕의 경사선·경사진 용마루/처마·차양 끝·그림자를 모두 수평 X/Y선으로 취급하지 않는다. 같은 3D 방향의 수평 모서리를 비교하고 경사 지붕선은 해당 면의 기울기·벽 상단·받침과 별도로 연결 검사한다. 최종 이미지의 선쌍과 대응 벡터를 기록하는 방법은 06을 따른다.

## 기본 블록과 단면 정합 — v2.5
베이스 상부 기준면은 네 모서리를 가진 하나의 평면이며, 아래쪽 기준면은 같은 평면 형상을 일정한 깊이로 내린 것이다. 상단과 하단의 대응 꼭짓점은 공통 수직축으로 이어지고 카메라 쪽 두 절개면은 평면으로 연결된다. 요청하지 않은 곡면 테두리, 둥근 코너, 다각형으로 잘린 모서리, 비틀린 보행면, 근거 없는 단면 두께 변화는 불합격이다. 흙·파손·배관의 불규칙함은 단면 내부나 국소적 파손으로 표현하며 베이스 전체의 기본 입체를 변형하는 이유가 되지 않는다.

화면의 모든 직각을 90도로 만들라는 뜻이 아니다. 상하 선군·대응점·두 절개면을 필수 정사영 기준으로 검사한다. 같은 깊이의 베이스 상하 대응 벡터가 방향/길이에서 모순이면 단면 정합 실패이며, 원근 효과로 면제하지 않는다. 이것만으로 물리적인 3D 두께 변화나 곡률을 측정했다고 말하지 않는다. 디오라마에 붙은 잘린 벽을 배경 예외로 인정하지 않는다.

바닥이 볼록하게 **읽히는 인상**, 외곽 직선의 실제 화면상 굽음, 투영/명암/포장 패턴의 단서를 구분한다. 긴 외곽선이 직선인데 가까운 모서리의 단면이 커 보인다면 투영과 상하 대응부터 확인한다. 단일 2D 인상으로 보행면의 실제 3D 곡률을 확정하거나, 직선 외곽만으로 평면 전체를 PASS 처리하지 않는다. 베이스 모서리와 중요한 기단은 판독 가능한 만큼 드러내며 가림으로 확인하지 못한 핵심은 UNCERTAIN으로 남긴다.

## v2.3 직교 건축과 지붕의 면 정합
승인: master_update_20260910_v2_3. 건물 바닥 외곽선과 플레이어 이동에 접하는 고정 외벽은 X/Y축에 평행한 선분으로 연결한다. 사선으로 깎은 모서리·회전된 건물·쐐기형 틈·곡선 보행 경계를 사용하지 않는다. L/T/U형, 직각 후퇴·돌출과 높이가 다른 날개·상층으로 다양화한다.
지붕은 경사·박공·톱니형·배럴형 등으로 달라질 수 있으며 아래 건물의 보행 경계는 직교 형태를 유지한다. 지붕 면/곡면의 경사 시작·끝, 용마루·골·처마, 벽 상단 및 받침을 일관되게 연결한다. 장비 지지 없이 경사면에 떠 있거나 비틀린 면을 의도적 디자인으로 정당화하지 않는다. 면 정합이 불명확하면 UNCERTAIN, 명백한 모순은 FAIL이며 최종 통과로 보고하지 않는다.
직교 제한은 탱크·자동차·트럭·소품의 원래 곡면/회전에 적용하지 않는다. 비건물도 공통 투영·접지와 기능 출구 접근 공간은 지킨다. 두 후방 경계는 방향과 연결 관계이며 동일한 벽 두 줄이나 정해진 문틀 좌표를 복제하는 규칙이 아니다.
