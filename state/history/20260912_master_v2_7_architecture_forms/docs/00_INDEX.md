## 충돌 해결
최신 사용자가 명시한 변경 > 해당 변경과 무관한 기존 마스터 > 장면별 기본 선택.
암묵적인 장르 관습이나 최신 생성물은 기존 마스터보다 우선하지 않는다.
“시가지”는 유럽풍 상점 복사나 네온 의무화를 뜻하지 않는다. “마트”는 중앙 장애물 허용이 아니다.
“좁은 공간”은 공통 공간 틀 안의 건물/길 배치를 조정하되 두 출구와 연속 보행 공간을 삭제하지 않는다. 기본 외형 예외는 사용자 명시 요청으로 구분한다.

장소 크기, 정확한 카메라 각도, 전체 치수, 낮/밤의 기본 팔레트는 수치로 확정되지 않았다.
현재 요청에 맞춰 선택하되 도해의 구조와 원본 구도의 인상을 유지한다.

## 현재 실행과 근거
필수 정사영/장면 구조안 → 역할별 참조 → [실행 프롬프트](../templates/generation_prompt.md)와 요구사항 대응표 → 실제 생성 → [최종 검수](06_QA.md) 순서다. 변경 이력은 생성 지시에서 제외하되 적용 조건은 유지한다.
최종 이미지는 정사영 필수이며 같은 축 선군의 평행성·일정 깊이의 상하 대응 벡터·거리별 화면 크기 유지를 검사한다. 참조 이미지의 원근은 복사하지 않는다. 계획 수치와 실제 결과 관찰을 분리하고 가려진 핵심 기단은 UNCERTAIN으로 남긴다. 입력 길이/장수는 실제 전달값과 확인된 도구 한도를 구분해 기록한다.
건물 직교 평면·두 기능 출구의 가변 위치/형태·비건물 경계·건물 입구 및 윗면40~80% 등 기존 조건은 유지한다. 03 아트 본문v2.2는 넓은 기본 색면과 온전한 면에도 드문 큰 방향성 평면 붓터치를 명시한다. 녹·박리와 구분하며 M03-10 대표 역할과 기존 LDI 표현 기반을 유지한다. 파일명 V2는 호환성을 위해 유지한다.
