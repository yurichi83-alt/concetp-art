이 폴더를 내 게임 배경 컨셉아트 작업 프로젝트로 사용해줘. 새 웹앱이나 이미지 생성 프로그램을 개발하는 요청은 아니야.

AGENTS.md와 START_HERE_KO.md를 읽고, 마스터 01~04 v2.4·생성 실행 규칙·원본 레퍼런스 경로를 확인해줘. scripts/validate_project.py로 파일 누락도 확인해줘.
이후에는 내가 “장소 / 시간대 / 소재 / 한 장”만 입력해도 기존 공간과 스타일 규칙을 유지해서 바로 이미지를 생성해줘.

현재 환경의 내장 이미지 생성 기능과 imagegen 스킬 사용 가능 여부를 먼저 확인해줘. 사용 가능하면 그 기능을 사용하고, 별도 과금 API나 추가 설치가 필요하면 실행 전에 알려줘. 전역 설정은 바꾸지 마.

준비가 되면 별도 재확인 없이 첫 테스트를 진행해줘:
교역장 / 밤 / 드럼통 / 한 장

정육면체형 공통 공간과 하나의 투영으로 구조안을 먼저 잡고, 중앙부터 두 출구 너머까지 물체가 침범하지 않는 보행 공간을 확보해줘. 베이스 상하 대응/평면 단면과 실내 이동 공간도 검사해줘. 파일로 접근 가능한 결과와 생성용 지시·참조 목록은 outputs에 저장하고, 생성 후 실제 이미지를 열 수 있으면 검수 결과도 남겨줘. 구조 오류가 있으면 알아서 수정·재생성하고 실제 결과를 다시 검수해줘.

현재 v2.4/실행1.5에서는 건물 지상 경계를 X/Y축 직교로 설계하고 지붕·높이·직교 매스로 다양화한다. 탱크·차량도 뒤쪽 경계 역할이 가능하다. 약11시/1시 방향의 기능 출구 두 개는 면 안 위치/형태가 자유이며 건물 입구 겸용·클리어 전 닫힘도 가능하다. 출구의 상태와 개방 후 연결을 기록하고, 이전 끝쪽 게이트 배치를 고정하지 않는다. 건물 입구·옥상40~80% 규칙은 건물에만 적용한다.

실행 지시는 templates/generation_prompt.md의 구조→현재 장면→아트/참조 역할 순서로 압축하고 요구사항 대응표로 누락을 확인한다. 실제 최종 이미지의 같은 축 선군·상하 대응 모서리를 선택한 투영 방식으로 검수하며, 가려진 핵심 근거는 불확실로 남긴다. 도구 입력 길이/장수는 실제 전달값과 확인된 제한을 구분해 기록한다.
