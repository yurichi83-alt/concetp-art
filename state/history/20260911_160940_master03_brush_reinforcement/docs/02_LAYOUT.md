## H01: 두 개의 뒤쪽 이동 경계
카메라 기준 상단 좌측면과 상단 우측면은 플레이어가 넘어갈 수 없어 보이게 구성한다.
꼭 연속된 건물/벽이어야 하는 것은 아니다. 건물·가벽·펜스·컨테이너·원통형 대형 탱크·자동차·트럭·산업 설비·잔해·낙차·지형을 장소에 맞게 활용할 수 있다.
서로 다른 요소 사이의 빈틈이 제3의 통로로 읽히지 않도록 경계를 연결한다.
같은 베이스의 인접한 두 뒤쪽 방향이 이루는 직교 관계와 차단·연결 기능을 유지한다. 물리적으로 곧은 담 두 개를 세우거나 두 건물을 같은 L자 덩어리로 배치할 의무는 없다. 직전 이미지의 건물 용도·폭·높이·실루엣도 반복하지 않는다.
H08의 건물 직교 평면 제한을 탱크·차량·소품의 실루엣까지 각지게 바꾸라는 뜻으로 확대하지 않는다. 원래 곡면·외형과 회전은 허용하되 공통 투영·접지·차단 기능과 출구 접근 공간을 지킨다. 물체의 형상 자유는 통로 점유 허용이 아니다.

## H02: 기능 출구 정확히 두 개
- 출구는 클리어 후 다음 공간으로 이동하는 전환 지점이다. 상단 좌측 경계 방향(약 11시)과 상단 우측 경계 방향(약 1시)에 각각 하나씩 배정한다. 이는 방향·연결 관계이며 고정 화면 좌표가 아니다.
- 각 면의 중앙·중간·끝, 대칭·비대칭 모두 가능하다. 새 장면에서 위치와 형태를 다시 선택하며, 이전 끝쪽 좌표를 자동 상속하거나 매번 강제로 위치를 바꾸는 규칙을 만들지 않는다.
- 독립된 문틀이나 열린 문만 사용하지 않는다. 건물 출입구·건물 내부 전환 통로·건물 사이 골목과 개폐 철문·시설 통로·계단·지하 주차장 램프 등으로 설계할 수 있다.
- 두 출구의 위치·역할과 접근 공간은 화면에서 식별 가능해야 한다. 건물 내부 전환에서는 모든 내부를 억지로 노출할 필요는 없지만, 입구 규모와 접근·전환 관계가 설득력 있게 읽혀야 한다.
- 브리프에 클리어 전 닫힘 / 클리어 후 열림 상태를 구분한다. 의도된 잠금 철문·셔터는 잔해로 막힌 실패 출구와 다르다. 닫힌 상태도 접근 공간, 개방 후 연결 경로, 문짝·셔터의 이동 여유를 계획한다. 열린 상태에서는 보이는 연결 동선에 장애물이 없어야 한다.
- 건물 입구가 지정 기능 출구를 겸할 수 있다. 같은 방향에 별도 출구를 추가할 필요가 없으며, 별도 기능 출구가 있으면 다른 건물 문은 장식 입구다. 출구 수는 문의 개수가 아닌 지정된 이동 기능으로 센다.
- 큰 열린 문·아치·골목 틈을 무심코 추가해 제3의 이동 통로로 읽히게 하지 않는다. 장식 입구는 깊이·닫힘 상태·내부 종결 등 장면의 표현으로 기능 출구와 구분한다.
- 계단·램프는 높이 방향의 이동 변화다. 평면 진행 방향과 접한 건물 경계는 공통 X/Y축에 맞추며, 연결 바닥과 높이를 설계한다. 후방 지정 출구에서 지하로 진입할 수 있지만 전면 토층 절개면을 제3의 출구로 만들지 않는다.
- 번호·EXIT 글씨·화살표·UI 표시는 작업 문서의 역할 기록을 대신하지 않는다. 사용자 요청 없이 이미지에 추가하지 않는다.

## H03: 높이
카메라에 보이는 차단 구조 높이의 상한은 약 6.5m. 더 낮아도 된다.
크레인·타워·옥상 장비가 추가되더라도 전체 장면을 과도하게 높이지 않는다.
이것은 계획 조건이며 생성된 2D 화면에서 실제 미터 단위를 정확히 검증할 수는 없다.

## H04: 중앙 비우기
- 중앙은 넓고 연결된 전투 바닥. 차량·진열대·키오스크·기둥·상자·기계·드럼통 등 장애물을 두지 않는다.
- 두 출구의 보행 보호 공간을 먼저 확보하고 그 밖의 외곽에 큰 물체를 둔다. 외곽이라는 이유로 통로를 점유할 수 없다.
- 평평한 색 변화, 작은 종이 등 낮은 바닥 묘사, 얕은 물웅덩이와 옅은 지면 안개는 허용한다.
- 쓰레기 요청이 있어도 중앙을 쓰레기 더미로 막지 않는다. 더미는 외곽, 중앙은 평평한 소량의 흔적만.
- 마트: 중앙 진열대를 만들지 말고 벽면/외곽에 선반과 조명 배치.
- 교역장: 중앙 노점/천막/큰 화로 금지. 교역 설비와 드럼통은 외곽.
- 고철 처리장: 집게·프레스·차량 적재는 외곽. 중앙으로 뻗은 붐/적재물을 피한다.
- 좁은 골목: 공간 폭은 줄이되 전투/이동이 연결되도록 구성한다.

## H05: 전면 가독성
전면은 카메라 시야가 열린 구성이다. 연속된 높은 담장·폐차 더미로 중앙과 단면을 가리지 않는다.
낮은 전면 디테일도 필요 최소한으로 사용한다. 전면을 또 하나의 폐쇄된 벽으로 만들지 않는다.

## H06: 접지와 지면 연결
건물 기초·문턱·포장·베이스는 01의 필수 정사영과 기준면에 맞춰 접지한다. 같은 지상 방향이 쿼터뷰 화면에서 사선으로 보여도 베이스·포장·기단·수평 벽 상단의 해당 선군은 공통 X/Y축을 따라야 한다. 최종 이미지에서 이들을 직접 대조하며 구조안의 정렬만으로 실제 접지를 통과시키지 않는다.
중앙에서 두 기능 출구까지 접근 공간이 연결되어 읽히고 출구의 계획된 개방 후 연결이 성립해야 한다. 건물 기단과 중요한 접촉 모서리는 상자·상품·잔해·차양 그림자로 모두 감추지 않는다. 실제 가림으로 축/접지가 판독되지 않는 핵심은 UNCERTAIN이며, 지붕 윤곽이나 계획상의 무충돌을 가려진 기단의 PASS 근거로 대신 쓰지 않는다. 건물의 지상 평면과 보행 경계는 H08을 따라 공통 X/Y축에 맞추고, 장면별 높이·직교 외곽선·지붕 형태를 다양하게 설계한다.
계단·경사·단차는 고저차의 이유와 접합이 분명하고 중앙·출구 동선과 시야를 보존하면 가능하다. 이를 건물 평면의 사선 회전이나 쐐기형 통로를 허용하는 근거로 사용하지 않는다.
고저차인지 생성 오류인지 분간하기 어려운 비틀림·끊김을 장식으로 정당화하지 않는다.

## 장소가 바뀔 때
골목·시가지·상점가·교역장의 차이는 시간대나 색감 외에도 건물 용도·매스·공간 폭·포장·외곽 시설에서 읽혀야 한다.
01·02의 필수 조건을 지키면서 장소에 맞는 배치와 출구 형태를 선택한다. 모든 항목을 억지로 바꾸거나 변경 개수를 정량화하지 않는다.
검수 시 조명과 색을 제외해도 새 장소로 구분되는지 확인한다(`docs/06_QA.md`).

## v2.3 경계의 기하 관계
카메라 기준 뒤쪽 좌·우의 두 논리적 경계 방향은 같은 베이스와 공통 공간 틀 안에서 직교 관계를 가진다. 각 방향에는 기능 출구 하나를 배정한다. 차단체는 건물·펜스·컨테이너·탱크·차량 등으로 구성할 수 있으며, 경계의 두 방향과 의도하지 않은 통로 없는 연결 기능을 지킨다. 실제 물체가 두 직선 벽을 그대로 따라야 한다거나 출구가 각 변 끝에 고정된다는 뜻이 아니다. 건물은 H08의 직교 지상 평면을 따르고 비건물 경계물은 본래 형상을 유지한다.

## v2.3 상태에 맞는 실제 보행 보호 공간
중앙 활동 공간에서 각 기능 출구의 전환 지점과 개방 후 연결부까지 연속된 보행 공간을 먼저 확보한다. 열린 출구는 현재 경로가 비어 있어야 하고, 클리어 전 닫힌 출구는 문 앞까지 접근 가능하며 문짝·셔터가 열린 후에도 경로와 작동 여유가 확보되어야 한다. 의도된 잠금 장치 이외의 상자·잔해·난간·돌출 기계·케이블은 두 상태 모두에서 통로를 침범할 수 없다. 바닥에 가느다란 빈 선이 보이거나 문틀만 보이는 것은 통과 근거가 아니다. 직각으로 꺾이는 길은 회전 구간의 여유 공간까지 확인한다. 외곽 배치는 통로 점유를 허용하지 않는다. 물체가 충돌하면 물체를 이동·축소·제거하거나 건물 배치를 다시 잡고, 길이나 베이스를 휘어 해결하지 않는다.

폭은 장면의 공통 사람 스케일로 계획하고 전체 구간에서 유지한다. 임의의 2m/2인 폭을 영구 수치로 고정하지 않는다. 보이는 접근로·문 작동 공간·연결 관계를 확인할 수 없으면 UNCERTAIN이다. 계획된 닫힘 상태나 내부 전환으로 보이지 않는 목적 공간 자체를 무조건 실패로 처리하지 않되, 기록만으로 보이는 막힘을 면제하지 않는다.

## H07: 내부 이동과 방 깊이
내부가 보이는 상점/시설은 입구, 연속 바닥, 내부 통로, 기능별 배치 공간과 뒷벽이 있는 실체적 방으로 계획한다. 외관 크기에 비해 내부가 얕은 진열 상자로 축소되거나 물건이 전면을 채워 이동할 수 없으면 불합격이다. 건물 기초·문턱·도로의 높이와 방향을 공통 기준면에서 맞춘다. 계획된 계단·경사·직각 회전은 가능하지만 연결과 접지가 명확해야 하며, 생성 오류를 의도적인 단차로 해석하지 않는다. 내부 전환 출구라고 해서 보이지 않는 모든 방을 절개해 보여줄 의무는 없다.

## H08: 건물 지상 평면과 직교 보행 경계 — v2.5

건물의 바닥 점유 형태와 플레이어 이동 공간에 접하는 고정 외벽은 장면의 공통 X/Y축에 평행한 선분으로 설계한다. 사선으로 잘린 건물 모서리·회전된 건물 배치·쐐기형 건물 틈·곡선으로 돌아가게 만드는 건물 경계는 사용하지 않는다. 단일 직사각형만 허용한다는 뜻은 아니다. L/T/U형 평면, 직각 후퇴·돌출, 높이가 다른 날개와 상층으로 다양화한다.

직각은 실제 수평 평면의 관계이며 화면에서 90도로 보일 의무가 없다. 같은 3D 방향의 선쌍은 필수 정사영의 평행성으로 비교하므로 화면 선 방향도 관찰 근거로 쓸 수 있다. 이 화면 각도를 실제 건물 회전각으로 곧바로 바꾸지 않는다. 소품·프랍·차량·탱크의 외형과 회전에는 건물의 직교 제한을 적용하지 않으며, 이들도 공통 카메라·접지·통로 보호를 지킨다.

구조안에는 위에서 본 건물 외곽선의 각 선분과 높이·지붕 면을 분리해 기록한다. 각 선분의 X/Y 정렬을 검사하고 최종 이미지의 보이는 기단·접촉 외벽과 대조한다. 큰 경계상자(AABB)의 무충돌이나 구조안 PASS는 최종 평면·지붕 정합 검사가 아니다.

건물 평면의 회전, 높이에 따라 달라지는 투영, 경사 지붕/차양, 그림자와 가림은 구분해서 판정한다. 지붕선 하나의 기울기만으로 건물이 회전했다고 단정하지 않는다. 기단이 가려져 평면을 확인하지 못하면 L07은 UNCERTAIN으로 남기고, 수평 벽 상단과 베이스의 같은 축에서 확인한 공통 투영 모순은 별도로 C04 FAIL에 기록할 수 있다. 경사선·용마루·처마는 실제 3D 방향을 먼저 분류하며 모두 수평 X/Y선에 강제로 맞추지 않는다. 지붕의 시작·끝·벽 상단·장비 받침 접합은 01·04 기준으로 따로 검사한다. 불명확한 면을 의도한 비정형이라는 설명으로 통과시키지 않는다.

## 건물 문/셔터와 기능 출구의 관계 — v2.3

각 건물에는 사람이 출입할 수 있다고 납득되는 문·셔터·출입구 중 최소 하나를 외관에서 식별 가능하게 설계한다. 실제 게임플레이 진입, 열린 문, 내부 구현을 의무화하지 않으며 닫힌 문이나 내려진 셔터도 가능하다. 사람 크기의 비례, 문틀·문턱·손잡이/셔터 구조 및 바닥과의 연결로 출입 용도가 읽혀야 한다. 작은 점검 패널, 환기구, 창문을 출입구 대신 세지 않는다.

건물 입구의 외관 기능과 맵 이동 기능은 역할상 구분하되 물리적으로 분리할 의무는 없다. 해당 건물 입구를 좌측 또는 우측의 지정 기능 출구로 사용할 수 있으며 이때 같은 방향에 별도 문틀을 더하지 않는다. 별도 기능 출구를 두었다면 같은 방향의 다른 건물 입구는 장식 입구다. 계획 기록에 건물마다 장식 입구 / 좌측 기능 출구 겸용 / 우측 기능 출구 겸용을 표시하고, 이 기록용 표시는 이미지에 삽입하지 않는다.

실내가 실제 보이는 경우 H07의 방 깊이/동선 규칙은 계속 적용한다. 건물별 윗면 40~80% 설계는 마스터04를 따른다. 건물용 출입구·윗면 규칙을 비건물 탱크·차량·설비에 기계적으로 적용하지 않으며 이들은 본래 기능에 맞는 접지·구조·연결을 검사한다.
