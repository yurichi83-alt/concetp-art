# 짧은 요청 해석

슬래시로 나눈 고정 문법만 강제하지 않는다. 자연어도 허용한다.
기본 슬롯: 장소 / 시간대·색감 / 소재·조명 / 공간 특성 / 장수.
모든 짧은 요청은 **Salvage Cyberpunk 세계관 + Little Devil Inside의 건축·재질·조명 표현** 안에서 해석한다.
사용자가 새로 말한 조건을 적용하고 나머지 마스터를 유지한다. 직전 장면의 개별 조건까지 자동으로 계승한다는 뜻은 아니다.

## 예시
| 요청 | 변경분 | 반드시 유지 |
|---|---|---|
| 교역장 / 밤 / 드럼통 / 한 장 | 교역 설비, 밤, 드럼통 | 중앙 비움, 외곽 노점/드럼통, 단면, 두 출구 |
| 도심 골목 / 낮 / 폐건물과 쓰레기통 / 좁은 공간 / 한 장 | 좁은 베이스, 외곽 폐건물/쓰레기통 | 연속된 중앙 바닥과 출구 접근로 |
| 실내 마트 / 어둡고 형광등과 가판대 조명 / 쿨톤 / 한 장 | 실내, 형광등, 외곽 진열대 조명 | 천장 절개, 중앙 진열대 없음, 단면, 두 출구 |
| 고철 처리장 / 폐자동차와 고철 처리 기계 / 밤 / 한 장 | 외곽 프레스·집게·폐차 | 장비 높이/시야 제어, 중앙 빈 공간, 두 출구 |
| 시가지 / 달빛 밤 / 낮게 깔린 안개 / 건물 위주 / 한 장 | 시가지 용도에 맞는 건물 매스·공간 폭·외곽 시설, 달빛과 지면 안개 | 두 출구·빈 중앙·전체 베이스, 안개가 단면/출구를 지우지 않음 |
| 낮·밤 다른 장소 / 두 장 | 서로 다른 장소와 조명 | 각각 독립 이미지. 비교 패널 금지 |

## 모호함 처리
“원톤”은 오타/웜톤/단일 색조 중 불명확하면 필요한 경우 짧게 확인한다.
장르 키워드만으로 오래된 정전 조건을 영구 활성화하지 않는다. 이번 장면에 전기 요청이 있으면 사용 가능하다.
“드럼통”만 있으면 외곽 소품으로 해석하고, 밤의 화로 사용은 합리적인 장면 선택으로 기록할 수 있다.
단, 모든 미래 장면에 드럼통 불을 강제하지 않는다.

## 반복 작업
새 장소 요청은 별도 시안이다. 건물 용도·매스·공간 폭·포장·외곽 기반 시설과 지면 단면의 기능을 새 장소에 맞춰 설계한다.
시간·색감만 바꾸고 직전 골목·상점가의 건물 배치, 문틀, 소품, 단면 배관을 그대로 복제하지 않는다.
장소 차이가 조명과 색을 제외해도 읽히는지 검수하며, 새 장소라고 공간 불변 조건까지 바꾸지는 않는다.

“방금 결과 유지”, “이 이미지에서 수정”이라고 하면 실제 해당 이미지를 확인하고 지정한 부분을 편집한다.
“기계 비중이 좋다” 같은 부분 선호는 승인된 시각적 비중만 참고한다. 이전 출력 전체나 특정 장치를 고정된 마스터로 승격하지 않는다.
이전 출력의 입력 여부와 허용 역할은 `docs/05_GENERATION_RULES.md`, `docs/10_CURRENT_REFERENCES.md`에 따라 결정하고 기록한다.

안개·밤·쓰레기·전봇대·좁은 골목 등 개별 장면 조건은 다음 새 장소 요청에 자동 누적하지 않는다.
“같은 조건으로 장소만 변경”처럼 연속성을 명시한 경우에는 그 범위를 유지한다.
형태 다양성은 큰 형태→외벽/기능 공간의 깊이→표면 순서로 설계한다. v2.7에서는 건물의 주된 배치와 직선 구조를 공통 X/Y축에 맞추면서 지상 곡면 외벽·둥근 기계형 건축도 허용한다. 날개·상층 후퇴/돌출·깊은 창/입구·계단·데크·지붕·큰 설비 부위로 실루엣과 용도 차이를 만들고, 임의 사선 회전·애매한 좁은 쐐기 틈·부자연스러운 접합은 피한다. 곡면을 모두 사각 받침으로 감싸거나 정사영 보정 때 개성을 단순 상자로 되돌리지 않는다. 베이스의 곡률·모따기 금지는 유지한다.
새 장면의 두 기능 출구는 상단 좌/우 방향을 유지하면서 면 안 위치·형태·개폐 상태·건물 입구 겸용을 다시 계획한다. 기존 끝쪽 게이트 좌표를 자동 상속하지 않고, 클리어 전 닫힘은 개방 후 연결·작동 여유와 함께 기록한다.
“검수만”은 생성하지 않는다. “마스터 수정”은 문서 변경이지 자동 이미지 생성 요청이 아니다.
“이번만”은 장면 예외. “앞으로 기본값”은 승인된 영구 변경. 승인 범위를 분리해 state에 기록한다.

## 건축·기계 키워드의 범위 — v2.7

- “2층이 기계 구조물”은 해당 층 자체를 비거주 설비 부피로 해석한다. 주거층 위에 장비를 조금 얹는 것으로 대체하지 않는다. 기계의 지지·연결·수리·현재 용도를 설계한다.
- 특정 L형·기계층·1층40%/2층20%·층별 면적·건물 수는 해당 요청에만 적용한다. 장면별 기계 비중은 건물별 옥상40~80%와 다른 조건이며, 기계층 위에 장비를 중복 증식시키지 않는다. 모든 장면에 곡면이나 특정 층 기계화를 강제하지 않는다.
- “시가지”는 상점가·슬럼·유럽풍 점포나 특정 건물 수를 뜻하지 않는다. 중앙과 두 출구 접근은 확보하되 길 폭·건물 관계·주변 점유를 장소별로 설계하고 같은 거대한 빈 마당을 반복하지 않는다. 낮은 소품만으로 후방 차단이 성립한다고 보지 않는다.
- 독립 시안은 좌우 반전·재색칠이나 색·층수·위치·작은 부품 변경만으로 대체하지 않는다. 큰 형태·외벽 깊이·배치·경계/연결의 차이가 읽혀야 하며 필수 변화 개수는 정하지 않는다.
- F-01~07은 큰 형태·외벽 깊이만 선택 입력하는 보강 자료다. F-08~11은 형태 비교 전용이며 생성 입력·기하 승인으로 사용하지 않는다. 기존27장·표면4장과 기본 우선순위를 유지한다.
- 실제 콜리전·메시·UV 제작/검증은 이미지 요청에 포함하지 않는다. 미검증 자체를 보류/실패 이유로 삼지 않되 이미지에서 보이는 경계·접지·두께·지지·연결·두 출구 동선은 검사한다.
