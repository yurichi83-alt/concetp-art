# 마스터 v2.5 갱신 — 최종 정사영 필수

승인: master_update_20260911_v2_5 / 2026-09-11.
사용자의 직접 갱신 요청에 따라 기존 카메라 규칙을 보강했다. 별도 조건을 중복 추가하지 않고 기존 약한 투시 선택 허용을 정사영 필수로 교체했다.

- 모든 최종 이미지는 하나의 정사영(orthographic) 카메라를 적용한다.
- 베이스·포장·건물·출구·소품·차량·자연물에 같은 카메라를 사용한다.
- 같은 3D 방향의 선군은 평행하고, 같은 실제 길이/방향의 화면 길이는 거리 때문에 변하지 않는다. 일정 깊이 베이스의 상하 대응 벡터는 방향/길이가 일치해야 한다.
- M01을 포함한 참조 이미지의 원근보다 필수 정사영 규칙이 우선한다.
- 실제 결과의 원근 혼입은 FAIL, 핵심 근거 부족은 UNCERTAIN이다. 프롬프트/구조안만으로 합격시키지 않는다.
- 쿼터뷰 회전각·높이·배율은 장면별로 선택한다. 특정 아이소메트릭 각도나 임의 픽셀 허용오차는 영구 고정하지 않는다.
- 기존 건물 직교 경계, 소품/차량/탱크 형태 예외, 출구/입구/옥상, 아트/세계관과 구조 보정 중단 기준을 유지한다.
