# 생성 전 점검

- 내장 `image_gen.imagegen` 사용 가능. 공식 imagegen 및 프로젝트 game-env-art 절차 사용. 외부 API, 설치, 전역 설정 변경 없음.
- 파일 누락 검사: `python3 scripts/validate_project.py` PASS (마스터 24, 선호 예시 2, review-only 3). 파일 무결성 검사이며 시각 검수가 아님.
- 최신 실행 규칙, project.json, manifest, 명시적 승인 기록 확인.
- 입력 5장: 사용자 첨부 + M02-01 + M01-01 + M03-11 + M04-02. 모두 실제 열람. M03-10도 검토했으나 입력 한도 때문에 이번 장면에 적합한 고해상도 M03-11로 표현 역할을 전달.
- 전체 베이스, 양면 단면, 정확히 두 후면 출구, 빈 중앙 및 접근로, 건물 접지와 계단 연결을 계획에 포함.
- 첨부의 물 반사·크롭·높은 전면 가림·과밀 표면은 복사하지 않음.
- 최종 한 장. 실제 구조 오류 발견 시 기존 상시 승인으로 보정하며 시안별 보존. 스타일만을 이유로 자동 추가 생성하지 않음.
- 약 6.5m 높이는 계획 조건. 단일 이미지에서 실제 수치나 후속 3면도/메시 정합을 검증했다고 주장하지 않음.
