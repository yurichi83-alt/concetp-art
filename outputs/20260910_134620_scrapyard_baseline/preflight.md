# 생성 전 확인

- 요청: 독립 신규2장 중 기본1장. 내장 image_gen 사용, 외부API/설치 없음.
- 마스터01~04, 실행05, QA06, project.json, 원본manifest와 현재 승인 확인.
- 구조안 직접 열람. 건물 외곽선 X/Y 직교 전부 통과, 경계·문짝·소품·차양 포함 보행 부피 충돌0. 두 기능 출구 상태와 건물 장식 입구 구분.
- 지붕은 서로 다른 높이의 평면, 받침/연결 계획. 고물상 약54%, 식료품 약60% 점유. 기계화50%는 고물상 건물 전체 구성의 별도 비율.
- 실제 입력5장: 이 run의 신규구조안/M02/M01/M03-10/M04-02. 전부 view_image로 확인. M03-11/M04-04도 검토했으나 입력수 제한상 제외.
- 다른 요청 이미지·구조안, 과거 생성물, 카세트 사용자 참고는 입력하지 않음.
- 최종 PNG를 별도로 열어 구조·동선·키워드를 검수하며 계획만으로 합격 처리하지 않음.
