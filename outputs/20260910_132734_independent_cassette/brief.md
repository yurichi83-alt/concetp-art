# Independent cassette daytime alley

요청: 도심 속 골목 / 낮 / 폐건물과 쓰레기통 / 바닥에 널린 쓰레기 / 카세트 퓨처리즘 컨셉 / 한 장.

신규 독립 생성 1장. 동시 요청의 다른 새 이미지나 구조안은 열람/참조하지 않았다. 기존 renderer의 투영/깊이 버퍼 유틸리티만 재사용했고 장면 좌표·용도·건물/출구·단면은 새 설계다. Master2.3 / execution1.4 / package1.3.0.

단일 평행 쿼터뷰, 16×16 정사각 평면을2.2두께로 수직 압출. 계획 수치이며 최종2D의 실제 미터/충돌 검증은 아님. 모든 건물 접촉벽은 공통XY 직교. A는 폐기록관의 직사각 외곽과 중앙 관통 통로, B는 폐작업장의L형 외곽과 낮은 날개. 상단 두 경계를 나머지 담/접합으로 막는다.

좌측11시 기능출구는 면 중간의A건물 관통 입구. 이미 열린 상태로 폭3, 높이2.8계획, 건물 입구 겸용이며 연결은x음의 방향. 우측1시 기능출구는B옆 열린 골목(면 끝 가까이), 접힌 문짝이 외측에 놓이며y음의 방향으로 다음공간 연결. B의 닫힌 사람문은 장식입구로 내부이동 기능을 추가하지 않는다. 두 출구에 기능 하나씩만 배정한다.

중앙 및 접근·회전·전환의 보행보호 AABB와 고정/소품 부피 충돌 없음. 건물 외곽선 선분축 검사는 별도 PASS. 지붕 면과 받침도 별도 계산했으며 A50.83%, B57.29%의 실제 설비 투영 점유. 평판/그림자/오염 제외, 다른 높이의B주지붕·날개는 각각 실제 면으로 지지한다. 최대 장치높이5.6계획.

LDI 표현은 넓고 조용한 면과 선택적 큰 파손. Salvage Cyberpunk는 남은 공동 전력/환기/폐기물 장치의 대체외장·어댑터·우회 덕트로 번역. 카세트 형태는 실제 사용자 참고의 두꺼운 외장·깊은 기계함·아날로그계기·큰 통풍구 언어만 사용한다. CRT/LCD/video/green screen 없음. 쓰레기는 낮은 종이·캔을 바닥에, 큰 봉투/통은 외곽에 배치.

실제 입력순서: structure_plan.png, M02-01, M01-01, M03-10, 사용자 카세트 원본의 보존사본. M03-11 및 M04-02/04는 열람했지만5입력 한도로 생략하며 세계관은 텍스트로 유지한다. A-01/A-02·미승인outputs·동시기본시안은 입력하지 않는다.
