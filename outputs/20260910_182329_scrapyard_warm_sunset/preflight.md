# 실행 전 확인

내장 image_gen.imagegen 및 공식 imagegen 스킬 사용. 별도 API/설치/전역 설정 변경 없음. 마스터24장 파일검사 PASS. 실행 규칙, project, manifest, 승인 기록과 현재 요청 확인.

선택한 M02-01/M01-01/M03-10/M04-02를 실제 열람했으며 4개 경로를 제출한다. 경로 입력 최대 수/내부 모델/토큰/재작성은 미확인이다. 실제4장 사용을 하드 한도로 해석하지 않는다. 이전 생성물은 기본 입력에서 제외한다.

최종 한 장. 실제 구조 오류 보정은 기존 승인 범위에서 run별 보존하며 수행. 구조 통과/도구 장애/관찰 불가/새 전략 없는 반복 시 중단. 아트 취향만으로 자동 재생성하지 않는다. 이미지의 실제 미터 치수와 3면도/UV는 미검증.
