# 폐차장 구조안

계획만 기록하며 생성 결과의 기하를 보증하지 않는다. 평행투영 쿼터뷰 선택. 공통 X/Y 수평축과 Z 수직축, 정사각형 평면과 일정 깊이의 직선 절개 블록. 상하 대응 모서리·양면 절개·펜스 기단을 노출한다.

계획 좌표는 임의 작업 단위 0~24의 정사각형, 지면 z=0, 하단 z=-2.5. 카메라는 (-X,-Y,+Z) 방향에서 바라본다. 건물은 없다. 모든 고정 패드/펜스는 X/Y 직교. 크레인은 이동식 기계 차량이며 건물 규칙 대상이 아니다.

- 좌후방 경계 y=24, 출구 x=8~12. 열린 슬라이딩 게이트, 문짝은 경계 안쪽 펜스 방향으로 완전히 후퇴. 접근 및 외부 연결 보호 x=8~12,y=7~24.
- 우후방 경계 x=24, 출구 y=5~9. 열린 슬라이딩 게이트, 접근 및 외부 연결 보호 x=10~24,y=5~9.
- 중앙 x=7~18,y=7~18의 연속 보행 공간과 위 연결을 보호. 문짝·돌출물·공중의 차량/붐도 침범 금지.
- 압착기 왼쪽 외곽 x=1~6,y=11~19. 프레스 안 승용차, 실린더/상판의 결합과 기반 지지. 중앙으로 전개되지 않음.
- 크레인 오른쪽 후면 적재 구역 x=17~22,y=16~22. 붐과 들어 올린 차체도 이 구역 안. 아웃트리거와 접지 확보.
- 나머지 외곽에 승용차·픽업·화물 트럭·압축 차체 적재. 두 출구와 패널 이동 범위는 비움. 앞쪽 적재 높이를 낮추고 모서리 관찰선 확보.
- 건축/실내 없음: L06/L07의 건물 검사와 W04/W05는 N/A. 고정 펜스·패드의 축/접지와 크레인/압착기 결합은 별도 검사.
- 단면의 전력 공급/기초와 배수·오일 분리 기능 구분. 닫힌 설비이며 이동 통로 없음.

사전 검토: 구역의 계획상 중앙/출구 침범 없음. 수치 계획은 실제 보행 폭이나 생성된 3D 치수의 검증이 아님. 최종 PNG의 두 축 선군, 상하 대응, 기단/장비 접지를 다시 검사해야 한다.
