# 장면 한정 표면 표현 테스트
사용자: 지금 답변을 마스터에 반영하지 말고 테스트 이미지 결과를 본 뒤 수정 여부 결정.
새 키워드가 없어 최근 완성 야간 장면을 비교용 편집 대상으로 선택했다.
내장 도구로 1장. M03-10과 최신 첨부를 함께 사용해 넓은 기본 색면 + 일부 가까운 톤의 큰 붓터치를 적용.
벽/도로/차체/지붕 표면의 색 변화와 손상은 분리한다. 기존 절반 수준으로 줄인 노후화, 밤/흰 조명/물웅덩이2개/경비실/자전거/배치 보존.
기존 붓질 금지와 QA S03의 포괄적 붓질 FAIL은 이번 요청에 한해서 위 지시로 대체. 마스터·템플릿·참조 원본·승인 기록은 수정하지 않는다.
요구사항 대응: 구조/출구/건물외관 보존→STRUCTURE/CURRENT SCENE→C/L/W 육안 검사. 표면 기본 색면/국소 붓질/미세 요철 제외→ART→벽/도로/차체 비교. 야간/두 웅덩이/소품→CURRENT SCENE→배치/광원 관찰.
