요청 범위: 실제 이미지 재검토·발생 원인 분석·이미지 생성 도구의 지시 수용 한계 확인. 재생성·메인 레퍼런스 변경은 수행하지 않음.

## 재검토 결론
기존 candidate_pass를 이번 재검토에서는 유지하지 않는다. 현재 판정은 **needs_revision**이다. 원본 결과·과거 review/result는 당시 기록으로 보존하고, 이 보고서와 recheck.json에 새 판정과 근거를 기록한다.
우측 상점의 공통 축 불일치는 확인된다. 다만 실제3D 회전각이나 물리적인 보행면 곡률을 단일2D 이미지로 확정하지 않는다.

## 선 방향과 두께
좌상단 원점, 오른쪽+X, 아래쪽+Y, 원본 해상도에서 수동으로 선택한 점이다. 각도는 atan2(dy,dx)로 계산한 화면 각도이며 수 도의 수동 판독 오차 가능성이 있다. 구조 가이드의 대응 선은 모두 같은 ±30도 선군이었다.

| 선 | 대략적인 끝점 | 화면 기울기 |
|---|---|---:|
| 베이스 상단 왼쪽 앞변 | (44,610) → (750,942) | +25.2° |
| 우측 상점 전면 파라펫 | (829,404) → (1128,502) | +18.1° |
| 베이스 상단 오른쪽 앞변 | (750,942) → (1352,622) | −28.0° |
| 우측 상점 오른쪽 파라펫 | (1128,502) → (1283,390) | −35.9° |

대응 선군 차이가 약7~8도다. 전면 벽 상단도 지붕과 비슷하게 기울어 있어 천막 경사만으로 설명하기 어렵다. 상점의 가려진 기단은 더 바닥에 가까운 각도로 읽히므로 건물 전체의 단일 회전보다는 **높이에 따라 달라지는 선 방향과 공통 투영 불일치**라고 표현하는 것이 정확하다. 이것은 실제 건물이7~8도 회전했다는 측정이 아니다.

바닥 상단의 긴 외곽선은 대체로 직선이다. 바닥 전체가 실제 볼록한 곡면으로 생성됐다고 확정할 증거는 부족하다. 그러나 일정 두께 정사영 프리즘이라는 지시에는 어긋나는 단서가 있다:
- 왼쪽 끝 상하 대응 높이 약87px, 가까운 모서리 약124px, 오른쪽 끝 약88px.
- 아래쪽 앞변은 약+27.6°/−30.6°로 위쪽+25.2°/−28.0°와 평행하지 않다.
- 가까운 모서리를 키우는 원근식 표현과 명암/포장 패턴이 볼록하게 읽히는 인상에 기여했을 가능성이 있다.

정투영이면 같은 깊이로 내린 수직 길이의 화면 벡터가 일정해야 한다. 원근 투영에서는 가까운 부분의 두께가 커질 수 있으므로 이 값만으로 실제 두께가 다르다고 할 수는 없다. 하지만 이번 계획은 one orthographic XYZ이며, 가게·바닥·상하단을 하나의 일관된 약한 투시로 설명할 수 있는지도 기존 검수에서 확인하지 않았다. 단순히 원근이라고 부르며 통과시켜서는 안 된다.

## 실제 이미지 도구에 들어간 내용
메인 레퍼런스 폴더 전체가 이미지 모델에 영구 학습되거나 매번 자동 전달되는 구조가 아니다. 이번 호출에서는 작업자가 기준 문서를 읽고 생성 프롬프트로 정리한 텍스트와 선택한 이미지 경로를 전달했다.
- 저장된 생성 프롬프트: 약7,600자, 공백 기준 약1,100단어. 정확한 문자열/바이트 통계는 recheck.json.
- 실제 이미지5장: 해당 시안의 새 구조안, M02 레이아웃, M01 구도/단면, M03-10 표현, M04-02 기계 세계관.
- structure_plan.json의 부피/외곽 좌표는 이미지 모델의 강제 형상 데이터로 제출되지 않았다. 모델은 구조안 PNG를2D 참고로 받았다.
- 다른 새 시안이나 이전 생성 장면은 이 호출의 이미지 입력에 포함되지 않았다.
- 호출 성공과 원본/저장본 일치는 확인된다. 토큰 잘림·조건 삭제·입력 초과 오류가 있었다는 기록은 없다.

## 도구의 제한: 알려진 것과 모르는 것
공식 문서는 GPT Image가 구조화된 구도에서 요소를 정확하게 배치하는 데 어려움을 겪을 수 있다고 명시한다. 카메라 사양도 정확한 물리 시뮬레이션을 보증하는 설정이 아니라 외형을 유도하는 단서로 설명한다.
출처: [Image generation—Limitations](https://developers.openai.com/api/docs/guides/image-generation#limitations), [Image prompting](https://developers.openai.com/api/docs/guides/image-prompting).

현재 공개된 내장 도구 계약에는 텍스트 최대 길이·모든 참조 경로의 최대 개수·내부 토큰 예산·참조 가중치·실행 중 재작성 텍스트가 노출되지 않는다. 따라서 현재 프롬프트의 여유 용량을 몇%라고 계산하거나, 내용이 절대로 생략되지 않았다고 보장할 수 없다.
5장이라는 숫자는 이번에 실제 전달한 수다. 도구의 최근 대화 이미지 선택 옵션 num_last_images_to_include에는 최대5가 명시되어 있으나, 이번 사용한 referenced_image_paths의 동일 상한은 공개 계약에서 확인되지 않는다. 이전 기록의 'five input slots' 표현을 전체 도구의 확정된 하드 한도로 해석하면 안 된다.
공식 앱 안내는 내장 image generation을 gpt-image-2로 설명하지만, 이번 개별 호출 반환값은 모델 버전/설정 정보를 제공하지 않았다. API의 다른 모델 한도나 품질 옵션을 이 호출에 그대로 적용하지 않는다.
[공식 앱 이미지 생성 안내](https://learn.chatgpt.com/docs/image-generation).

Responses API는 프롬프트 자동 수정과 revised_prompt 반환을 별도로 문서화한다. 이번 내장 도구가 같은 수정을 했는지, 실제 내부 프롬프트가 무엇이었는지는 확인할 수 없다.
[Responses API의 revised prompt 설명](https://developers.openai.com/api/docs/guides/image-generation#revised-prompt).

## 발생 원인 분석
확인된 직접 원인: 구조안은 정합했지만 최종 PNG에서 선 방향/투영이 달라졌고, 그 차이를 검수에서 놓쳤다.
가능한 기여 요인(통제 비교 실험이나 내부 추적을 하지 않았으므로 가설):
1. 2D 생성은 좌표를 고정하는3D 렌더러/제약 솔버가 아니며 구조안을 외형 참고로 재해석한다. 프롬프트의 orthographic-style 표현도 정확한 투영 고정보다 쿼터뷰 분위기로 읽힐 여지가 있다.
2. 구도/레이아웃/실제 상점 사진풍 게임 스크린샷/캐릭터 기계 참조가 서로 다른 시점과 장면 정보를 포함한다. 역할은 명시했지만 참조의 카메라 영향을 수학적으로 차단하는 기능은 확인되지 않는다.
3. 단면·출구·건물 직교·반기계화·옥상 비율·입구·상품·기계 다양성·스타일·금지 요소를 긴 한 번의 지시에 함께 맡겼다. 조건 사이의 우선순위가 결과에서 완벽히 실현되리라는 보장은 없다. 이것은 메모리 포화나 특정 문장 무시의 증거가 아니다.
4. 요구사항을 추가할 때 실행 프롬프트와 검수 방법의 간결성·측정 가능성을 함께 다듬지 못했다. 이미 '곡률 금지·공통 축' 규칙은 존재하므로 같은 금지 문장을 더 붙이는 것만으로 해결된다고 보기 어렵다.

## 권장 보강 방향 — 제안만
- 메인 기준의 요구사항은 보존하고 실행용 프롬프트를 구조 필수 조건 / 이번 장면 / 표현 지시로 짧게 정리한다. 과거 설명·중복·수치처럼 보이지만 강제되지 않는 장황한 문장을 줄인다.
- 작업별3D 구조안은 계속 만들되, 최종 이미지의 베이스 상·하단/지붕/외벽/기단/포장 선군을 실제로 대조한다. 목표 투영을 먼저 고정하고 정사영과 약한 투시의 검수 기준을 섞지 않는다.
- 구조 레퍼런스가 투영 기준이며 스타일 참조는 재질·색·디테일 표현에만 쓰이도록 구분한다. 참고 이미지 수를 늘리는 것을 해결책으로 삼지 않는다.
- 건물 기단과 베이스 모서리를 검수 가능한 만큼 드러낸다. 가려졌으면 PASS 대신 UNCERTAIN으로 남긴다.
- 모델링 기준으로 쓸 정도의 정확성이 필요하면3D 블록아웃/카메라/기하를 실제 원본으로 유지하고 생성 이미지는 표현 탐색에 활용하는 방식이 더 통제 가능하다. 현재 도구에는 좌표·depth/normal·참조별 강도·시드 고정 등의 제어가 노출되지 않아 생성만으로 정확성을 보장할 수 없다.

위 제안은 아직 메인 레퍼런스에 반영하지 않았다. 이번 결과도 재생성하지 않았다.
