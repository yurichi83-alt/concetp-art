# 이미지 모델 표기 정정 — 2026-09-11

**Codex에서 Images2.5를 사용하려면 별도 API가 필수라는 안내와, 방금 내장 출력을 확인된 Image2 기준 표본으로 분류한 설명을 철회한다.**

OpenAI의 [2026-09-08 공식 발표](https://openai.com/index/introducing-chatgpt-images-2-5/)는 ChatGPT, ChatGPT Work, Codex의 모든 요금제 및 데스크톱/모바일/웹에 Images2.5를 제공/출시한다고 명시한다. 한편 확인했던 [사용 문서](https://learn.chatgpt.com/docs/image-generation)에는 여전히 내장이 gpt-image-2라는 표기가 있다. 이 불일치를 확인하지 않고 사용 문서 하나를 실제 세션 모델의 증거로 취급한 것이 오류다. 문서 갱신 지연이나 내부 라우팅의 구체적 원인은 확인하지 못했다.

- 제품 제공 범위: Codex도 Images2.5 대상임이 공식 발표로 확인됨.
- 실제 이번 호출: imagegen 응답에는 image_url과 output_hint만 있었고 모델/스냅샷은 없었다. 따라서 방금 이미지가2인지2.5인지 실행 메타데이터로 확정할 수 없다. 제품 발표만으로 개별 호출의 세부 모델까지 증명하지 않는다.
- 도구 계약: 현재 제공된 내장 도구에는 model 인자가 없다. 내가 이 도구에서2와2.5를 직접 선택·전환했다고 주장할 수 없다.
- API: 별도 개발자 호출을 선택하면 키/별도 과금이 필요하지만, Codex 내장 Images2.5의 필수 조건은 아니다. API 호출은0회다.
- 기존 생성물: 이미지 자체/프롬프트/레퍼런스/QA 관찰을 보존하고 모델 표시만 정정. 최종 모음 파일명은 20260911_090939__builtin_first_output.png.
- 비교 계획: 이 내장 결과를 확인된2 기준으로 삼은2→2.5 비교는 성립하지 않는다. 필요시 현재 내장 대 API의 명시 모델 비교, 또는 동일 API경로에서 명시적인2 대2.5 비교로 다시 정의해야 한다. 지금은 API 실행을 보류한다.
- API SDK 준비: 작업 전용 가상환경에서 진행 중이던 설치를 중단했다. 설치 완전성은 미검증이며 내장 이미지 생성에는 필요 없다. 키/결제/전역 모델 설정 변경 없음.

정정 전 메타데이터는 metadata_before_rollout_correction/에 보존했다. 역사적 run폴더명은 유지하지만 모델 버전의 증거가 아니다. 마스터 레퍼런스는 수정하지 않았다.
