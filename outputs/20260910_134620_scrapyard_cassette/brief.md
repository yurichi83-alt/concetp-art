왼쪽 고물상은 긴 직교 건물로, 길이 기준 절반씩 낡은 작업실과 건물 체적 자체가 압축·선별 기계로 된 부분을 구성한다. 오른쪽에는 낮고 별도인 식료품 상점을 두며 중앙은 비운다. 서로 다른 높이의 수평 지붕, 넓은 열회수·환기 장치와 냉장·저수 설비의 지지면을 정의했다. 카세트 표면을 단일 아이보리 상자 모듈로 반복하지 않고 두꺼운 주물·타원형 기계 덩어리·깊은 캐비티·아날로그 계기를 건물 몸체에 통합한다.

왼쪽 약11시 기능 출구는 고물상 작업실의 닫힌 롤셔터와 겸용이다. 면 중간 위치, 문 앞 3.6×2.8 계획 접근 공간, 셔터가 수직 상승한 뒤 건물 안으로 연결되어 왼쪽 경계 바깥으로 이어진다. 내부 전체를 보여주는 요구는 없으며 문 크기·접근·수직 개방을 설계했다. 오른쪽 약1시 기능 출구는 기계화 고물상과 식료품 상점 사이의 열린 설비 통로이다. 면 중간에 위치하며 최소2.2 계획 폭으로 후방 바깥과 이어진다. 중앙부터 양쪽 출구까지 지상 장애물 겹침이 없음을 계획에서 검사했다. 수치는 최종 이미지나 실제 게임의 검증 수치가 아니다.

각 건물 사람용 입구: 작업실 셔터는 왼쪽 기능 출구 겸용, 식료품점 닫힌 유리문은 장식 건물 입구. 기계의 대형 서비스 캐비티는 바닥 피드 트레이와 구동부가 있는 종결된 장치이며 제3의 출구가 아니다. 건물 지상 외곽선 각 변은 공통X/Y축 정렬. 인접한 두 후방 차단 방향은 건물, 재사용 펜스와 외곽 컨테인먼트로 연결한다.
