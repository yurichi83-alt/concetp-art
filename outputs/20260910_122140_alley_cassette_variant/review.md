# 카세트 퓨처리즘 비교본 시각 검수
상태: candidate_pass. 실제 생성 이미지를 기본안과 시각 비교함. 사용자 승인 및 마스터 승격 아님.
- C01 PASS: 전체 베이스와 경계가 프레임 안에 유지.
- C02 PASS: 두 전면 평면 단면, 토층/기초/배관과 대응 모서리 유지.
- C03 PASS: 직선 프리즘 바닥. 기계 케이스의 둥근 모서리가 베이스에 전이되지 않음.
- C04 PASS: 주요 건물·포장·지붕 축이 기본안의 공통 쿼터뷰를 유지. 수학적 투영 정밀 검증은 아님.
- L01 PASS: 뒤쪽 두 직교 경계 유지.
- L02 PASS: 왼쪽과 오른쪽 각각 하나씩 정확히 두 외부 출구와 문턱 유지.
- L03 PASS: 기계부가 주로 기존 장치/벽에 붙어 있으며 중앙부터 출구 너머까지 장애물 없음.
- L04 PASS: 전면 가림 없음.
- L05 PASS: 장치와 지붕의 지지, 건물의 지면 접합 유지.
- L06 N/A: 내부 이용 공간을 보여주는 요청 아님. 문과 셔터 닫힘.
- W04 PASS: 사람용 문과 셔터가 읽히며 장치가 출입구를 덮지 않음.
- W05 PASS(시각 추정): 두 건물 지붕의 설비 점유가 기본안과 유사하고 정비 여백 유지. 정밀 면적 측정 주장은 아님.
- 기계 변경 확인: 왼쪽 옥상 긴 환기장치와 보조 모듈, 오른쪽 탱크 계기부/펌프/서비스 모듈, 외벽 및 출구 기둥 제어함, 양쪽 쓰레기통, 지하 접속 장치에 밝은 케이스·어두운 제어판·주황 손잡이/카트리지 삽입부·물리 계기 적용.
- 녹색 CRT와 기타 비디오 화면 없음.
- 건물 매스, 창문 손상, 출입문, 큰 쓰레기 더미와 중앙 종이, 조명과 카메라 구도를 유지해 직접 비교 가능.
- 한계: 생성 편집이므로 일부 표면 질감/미세 쓰레기 형태와 설비 주변 그림자는 재해석됨. 픽셀 동일 편집 또는 정확한 3D 치수 일치로 보고하지 않음.
- 표현은 기본안과 동일하게 마스터보다 손상 묘사가 촘촘한 편. 취향만으로 추가 변형 생성하지 않음.
