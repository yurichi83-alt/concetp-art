# 생성 전 확인

현재 실행 규칙·project·manifest·활성 승인과 사용자 요청 확인. game-env-art와 공식 imagegen의 내장 경로 사용. 외부 API/설치/전역 설정 변경 없음.

원본 M02-01/M01-01/M03-10/M04-02는 이 세션에서 실제 열람한 자료이며 이번 호출에도 실제 경로4개로 전달. 신규 장소에 이전 생성물은 입력하지 않는다. 실제 입력4장은 하드 한도 주장 아님. 높이 상한 예외만 이번 사용자 층수 범위로 기록, 마스터 변경 없음.

최종 한 장, 관찰된 구조 오류는 기존 승인에 따라 보정하고 시도별 보존한다. 불확실을 PASS로 덮지 않는다.
