작성: 2026-09-10. 상태: 승인 대기 제안. 메인 레퍼런스 v2.2 / 실행 v1.3 유지.
이번 작업은 첨부 이미지 분석 및 현재 문서 대조다. 이미지 생성, 마스터 갱신, 승인 기록 추가는 하지 않는다.

## 1. 결론과 이번 제작의 문제
출구 위치·형태의 자유, 건물 이외 물체로 경계를 만드는 자유는 이미 메인 문서에 있다. 이번에 전부 새로 추가할 규칙은 아니다. 제가 생성 지시에서 그 자유를 축소하고 동일 출구 좌표를 재사용했다. 반대로 건물 다양성은 사선/오각형 지상 평면으로 해석했다. 사용자 게임 동선 의도와 맞지 않는 제작 판단이었다.

첨부 건물은 두 문제를 분리해 봐야 한다.
- 기하 정합: 지붕의 평평한 후면과 경사진 전면의 면 구분·접합선, 꺾인 처마와 벽 상단의 대응이 명확하지 않다. 위 장비의 받침과 지붕의 연결도 명확한 평면 구조로 확인되어야 한다. 이 이미지만으로 정확한 3D 교차/각도 값을 측정할 수 없지만, 그 불확실성을 의도적 비정형이라는 이유로 PASS로 처리해서는 안 된다.
- 게임 동선: 건물 사이와 보행 바닥에 접한 벽체의 사선/쐐기형 모서리는, 기하가 수학적으로 올바르더라도 이번에 명확히 지정한 건물 직교 평면 규칙에 맞지 않는다. 모델의 우연한 일그러짐만이 아니라 제가 프롬프트에 명시한 대각선 건물 설계도 원인이다.
- 이전 검수의 문제: outputs/20260910_124620_alley_polygon_building_fix/review.md:6에서 의도적 꺾임이라고 C04 PASS를 부여했지만, 계획의 의도와 최종 면 정합을 충분히 구분하지 못했다. 이번 별도 재평가에서는 최종 승인 후보로 권하지 않는다. 과거 파일은 이력으로 보존한다.

정투영 화면에서 직각 건물의 벽이 사선으로 보이는 것은 정상이다. 새 규칙의 직각은 화면 픽셀 각도가 아니라, 위에서 본 실제 공간의 공통 X/Y축과 건물 경계의 관계를 뜻한다.

## 4. 승인 후 넣을 권장 문안

### A. 건물의 지상 평면과 기하
건물의 바닥 점유 형태와 플레이어 이동 공간에 접하는 고정 외벽은 장면의 공통 X/Y축에 평행하게 설계한다. 외벽은 직교하는 선분으로 연결하며, 사선으로 잘린 건물 모서리·회전된 건물 배치·쐐기형 건물 틈·곡선으로 돌아가게 만드는 건물 경계를 사용하지 않는다. 단일 직사각형만 허용한다는 뜻은 아니다. L/T/U형, 직각 후퇴와 돌출, 높이가 다른 날개와 상층으로 다양화한다.

화면상의 사선은 쿼터뷰 투영 결과일 수 있으므로 금지 대상이 아니다. 실제 수평 평면에서의 건물 방향과 경계 선분을 검사한다. 소품·프랍의 외형과 회전에는 이 직교 제한을 적용하지 않는다. 소품도 공통 투영·접지·출구 통로 보존은 지킨다.

### B. 지붕과 비정형 표현
다양성은 건물 지상 평면의 사선보다 상층 후퇴·층별 높이·직교 매스 결합·경사지붕·박공지붕·톱니형 지붕·배럴형 지붕·차양·연결 설비에서 만든다. 지붕이 경사져도 아래 건물의 보행 경계는 직교 형태를 유지한다.

경사는 실제로 정의된 지붕 면으로 표현한다. 경사 시작/끝선, 용마루/골/처마, 벽 상단과 받침이 일관되게 연결되어야 한다. 장비를 경사진 면 위에 띄우거나, 꼬인 한 면을 비정형 지붕으로 정당화하지 않는다. 구조가 읽히지 않으면 UNCERTAIN, 명백한 모순은 FAIL이며 최종 통과로 처리하지 않는다.

### C. 두 기능 출구의 방향·위치·상태
기능 출구는 정확히 두 개이며, 상단 좌측 경계 방향(약11시)과 상단 우측 경계 방향(약1시)에 각각 하나씩 배정한다. 이는 방향/연결 관계이지 고정 좌표가 아니다. 각 면의 중앙·중간·끝, 대칭·비대칭 모두 가능하다. 원본 도해의 출구 좌표나 이전 구조안의 양 끝 위치는 고정 기준이 아니다.

출구는 클리어 후 다음 공간으로 이동하는 전환 지점이다. 독립된 문틀이나 열린 문으로만 만들지 않는다. 건물 출입구·건물 내부로 이어지는 통로·건물 사이 골목과 개폐 철문·시설 통로·계단·지하 주차장 램프 등으로 설계할 수 있다.

클리어 전 닫힌 상태와 클리어 후 열린 상태를 브리프에서 구분한다. 의도된 잠금 철문/셔터는 잔해로 막힌 실패 출구와 다르다. 닫힌 상태라도 출구의 위치와 역할, 접근 공간, 개방 후 연결될 경로 및 문짝의 이동 여유를 계획한다. 열린 상태에서는 실제 보이는 연결 동선에 장애물이 없어야 한다. 사용자 요청 없이 화면에 번호/화살표/EXIT 표기를 넣어 구분하지 않는다.

계단/램프는 높이 방향의 이동 변화이며, 평면상 사선 건물 통로를 허용하는 예외가 아니다. 평면 진행 방향과 건물 경계는 X/Y축에 맞추고, 연결되는 바닥과 높이를 설계한다. 뒤쪽 지정 출구에서 지하로 진입하는 것은 가능하나, 전면 토층 절개면을 제3의 출구로 사용하지 않는다. 출구가 건물 내부 전환이면 모든 내부를 화면에 억지로 드러낼 필요는 없지만, 입구 규모와 접근·전환이 설득력 있게 읽혀야 한다.

### D. 건물 입구와 맵 출구의 역할 관계
건물마다 외관상 납득되는 사람용 입구를 마련한다. 이 입구는 기본적으로 건축 설득력을 위한 표현이며 실제 게임플레이 진입 의무가 없다.

해당 입구를 지정된 두 기능 출구 중 하나로 사용할 수 있다. 그러면 같은 방향에 별도의 출구를 추가할 필요가 없다. 별도 기능 출구를 배치했다면 같은 방향의 나머지 건물 문은 장식 입구로 취급한다. 출구 수는 보이는 문의 개수가 아니라 지정된 이동 기능으로 센다.

계획 기록에는 건물 입구마다 장식 입구 / 좌측 기능 출구 겸용 / 우측 기능 출구 겸용을 표시한다. 이 표시는 작업 문서용이며 이미지에 텍스트로 삽입하지 않는다.

### E. 경계를 만드는 물체의 종류
상단 두 방향의 경계는 플레이어가 넘어갈 수 없다고 인지되는 차단 구성이면 된다. 연속된 벽이나 건물 두 동을 반드시 세우지 않는다. 건물·가벽·펜스·컨테이너·원통형 대형 탱크·자동차·트럭·산업 설비·잔해·지형 등을 장소에 맞게 조합할 수 있다. 물체 사이 틈이 의도하지 않은 제3의 기능 통로로 읽히지 않도록 배치한다.

건물의 직교 평면 규칙을 탱크·차량·프랍의 원래 실루엣까지 각지게 만들라는 뜻으로 확대하지 않는다. 원통 탱크의 곡면과 차량 외형은 유지할 수 있다. 배치는 두 방향의 차단 역할 및 넓고 읽기 쉬운 출구 접근 공간을 확보해야 한다. 소품의 형상 자유와 통로 점유 허용은 별개다.

건물용 사람 입구와 지붕40~80% 규칙을 탱크/차량에 기계적으로 적용하지 않는다. 건물로 설계한 대상에는 계속 적용하고, 비건물 경계물은 그 기능에 맞는 접지·구조·연결로 검수한다.

### F. 제작 및 QA 적용
구조안은 건물의 위에서 본 외곽선과 높이/지붕 구조를 분리해 계획한다. 건물 경계 각 선분이 공통 X/Y축에 평행한지 확인하고, 통로 부피 및 두 출구 역할·상태·연결 경로를 검사한다. 큰 경계상자 간 충돌 없음만으로 건물 기하가 맞다고 판단하지 않는다.

기능 출구마다 방향, 해당 면 안의 위치, 형태, 개폐 상태, 클리어 후 연결, 건물 입구 겸용 여부를 기록한다. 새 장면에서는 이 항목을 다시 선택하며 이전 끝쪽 좌표를 자동 상속하지 않는다. 그렇다고 매번 무조건 위치를 바꾸거나 특정 회전 순서를 강제하지도 않는다.

최종 이미지 검수에서 C04/L05는 지붕 면 정합·벽 상단 대응·기계 지지까지 확인한다. 건물 직교 경계 검사를 별도로 추가한다. L02는 두 기능 출구의 역할과 방향/상태, L03는 해당 상태와 개방 후의 연속 이동 공간을 판단한다. W04는 장식 입구와 출구 겸용을 허용해 판정하고 W05는 건물에만 적용한다.
분석/보강안/마스터 갱신 요청에서는 오류를 발견해도 이미지를 자동 생성하지 않는다. 현재 분석 요청에도 동일하게 적용했다.
