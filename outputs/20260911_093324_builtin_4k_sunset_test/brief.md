# 내장 도구 4K 출력 테스트

사용자: 공식 발표상 Codex도2.5 대상이라는 전제에서 앞선 키워드를 그대로 사용해4K 해상도 출력 테스트.

키워드: ㄱ자 건물 / 노을 진 저녁 / 도로에 노란 모래60% / 오토바이와 자동차 / 벽면 낙서 / 부러진 전봇대 / 한 장.

마스터 v2.4, 실행 v1.5. 기본 Salvage Cyberpunk와 평행투영 쿼터뷰. 카세트 변형 아님. 앞선 공통 프롬프트의 구도 비율/픽셀 요청만16:9·3840×2160으로 변경하고 나머지 텍스트를 보존한다. 동일한 원본4장을 같은 순서로 제출하며 앞선 생성 이미지는 입력하지 않는다.

구조안 및 요구사항 대응은 원본 비교 요청의 structure_plan.json과 brief.md 시각 요구사항 표를 계승한다. API관련 계획/모델표시는 계승하지 않는다. 원본 모델 표기 정정은 유지: 제품 발표상 Images2.5 Codex 제공, 실제 호출 모델명/스냅샷 미확인.

테스트의 주된 측정: 도구에서 반환한 원본 래스터의 실제 가로·세로. 픽셀 인자가 없는 현 내장 계약에서 자연어 요청을 전달한 시험이며4K 성공을 사전 보장하지 않는다. 확대/보간/크롭 없이 원본을 보관한다.4K 미달 반환 시 그 사실이 시험 결과이며 API로 자동 전환하지 않는다.

실제 이미지 QA는 C01-C04/L01-L07/W04-W05/아트/키워드 순서.4K미달+기하불일치 시 동일 자연어 반복으로 한계를 해결했다고 주장하지 않고 첫 테스트 출력을 보존한다.
