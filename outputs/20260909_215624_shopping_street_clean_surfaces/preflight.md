# 생성 전 계획 점검

- 내장 편집 도구 및 referenced_image_paths 사용 가능.
- 편집 대상은 실제 열람. 새 LDI 5장 모두 대화/파일로 열람; 원본 형식 그대로 run inputs에 보존.
- PLANNED: 한 장, 동일 쿼터뷰와 전체 베이스, 정확히 두 출구, 중앙/접근로 개방, 양면 단면.
- PLANNED: 벽·바닥 미세 표면정보 제거, 뚜렷한 형태 경계·재질 구분 유지.
- PLANNED: 2번의 건물만 참고하고 자연물 제외.
- 마스터는 갱신하지 않음. 출력은 후보이며 사용자 승인 아님.

- 도구 입력 검증에서 총 5장 제한 확인. 생성 미실행 상태에서 입력을 편집 대상+자료1~4로 조정. 자료5는 분석만 텍스트 반영.
