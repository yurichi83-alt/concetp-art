# 메인 레퍼런스 v2.4 갱신

승인 발언 “좋아 보강해줘”에 따라 마스터 세트 v2.4, 생성·검수 실행 규칙 v1.5, 패키지1.4.0으로 갱신했다.

## 반영 내용

- **최종 기하 근거:** 생성 전에 투영을 하나로 선택하고, 최종 이미지에서 베이스 상하단·포장·건물 기단·수평 벽/지붕의 같은 방향 선을 대조한다. 정사영은 평행성과 상하 대응 벡터를, 약한 투시는 공통 소실점·지평선과 깊이에 따른 변화를 확인한다.
- **불확실 판정:** 가려진 기단은 계획이 맞아도 합격 처리하지 않는다. 화면 선의 차이를 실제3D 회전각으로, 볼록한 인상을 입증된 바닥 곡률로 단정하지 않는다. 한 사례의 각도/픽셀값을 보편 허용오차로 만들지 않는다.
- **간결한 실행 지시:** 구조 필수→현재 장면→아트/참조 역할 순서의 [프롬프트 템플릿](../../templates/generation_prompt.md)을 추가했다. 변경 이력과 중복 설명을 줄이고, 적용 요구사항은 실제 프롬프트 구절 및 계획/검수 항목의 대응표로 확인한다.
- **참조·도구 기록:** 구조 자료와 스타일 자료의 역할을 분리한다. 실제 전달 프롬프트의 글자/UTF-8 바이트/단어 수, 이미지 수·경로와 확인된 도구 한도를 기록한다. 최근 이미지 선택 옵션의5장 제한을 경로 입력 제한으로 확대하지 않는다. 공개되지 않은 내부 한도나 재작성은 미확인으로 남긴다.
- **재검토 이력:** 이전 고물상·식료품점의 candidate_pass는 별도 [재검토](../20260910_140555_scrapyard_geometry_recheck/recheck.json)의 needs_revision으로 대체해 현재 사용에 반영하고, 당시 이미지/검수 기록은 보존했다.

## 적용 파일과 보존

마스터01·02, 생성05·검수06, 현재 참조 정책, 프로젝트 데이터·승인 이력·진입 지침·프로젝트 스킬과 템플릿을 동기화했다. 기존26파일 변경, 실행 프롬프트 템플릿1개 추가다.

기존 마스터24장·선호2장·검토3장 총29장의 이미지 파일과 참조 역할을 그대로 유지했다. LDI 아트/Salvage Cyberpunk 세계관, 직교 건물·두 기능 출구·건물 입구·건물별 윗면40~80% 등 기존 조건과 앞선 승인 기록도 보존했다. 변경 전28문서는 [스냅샷 목록](../../state/history/20260910_141650_master_v2_4/snapshot_manifest.json)에 기록되어 있다.
