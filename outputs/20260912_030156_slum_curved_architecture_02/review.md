# 곡면 건축 시험 — 실제 이미지 검수

검사 대상은 이 폴더의 image.png 원본(1254×1254)이다. 저장한 PNG를 실제로 열었다. 구조안/가이드의 계획 적합성과 최종 결과 판정은 분리했다. 마스터 v2.6 / 실행 v1.7을 적용하되 현재 사용자의 지상 곡선 허용을 L07에 이번만 우선 적용했다.

곡면은 직교 컬리전으로 막을 때 넓은 빈 모서리가 보이지 않는지 시각적으로만 검사했다. 곡면 접선과 경사진 지붕은 수평 축 비교에서 제외했다. 실제 콜라이더·미터 치수·3면도·UV는 제작/검증하지 않았으며 requires_3d_validation이다. 아래 좌표는 원본 좌상단을 (0,0)으로 수동 판독한 근사치이며 수 픽셀 오차가 있다. 수치가 공통 허용오차나 실제 3D 회전각을 뜻하지 않는다.

| S02 | PASS 후보 | 설비는 건물 가장자리와 옥상, 고철은 작업장 주변에 모이며 중앙은 상대적으로 비어 있음 |
| S03 | UNCERTAIN | 입체는 명확하나 금속의 가는 선·손상 밀도에 모형 렌더 성향이 남음. LDI 표현의 최종 선호는 사용자 평가 필요 |
| S04 | PASS 후보 | 건물 부피, 층 구분, 외부 계단/설비 결합을 읽을 수 있음. 3면도·메시 정합을 검증한 것은 아님 |

| W03 | PASS 후보 | 단면 외에 A의 외벽 및 C 옆 기계에서도 기계적 존재감이 드러남 |
| W04 | PASS | A 사람용 문/셔터, B 고철상 셔터와 상층 주택 문, C 사람용 문 식별 |

기계 40%/20%는 A의 층별 외벽에서 기계로 읽히는 비중의 설계 목표이며 옥상 점유율과 다르다. B 절반은 2층 주택의 평면 면적 목표이다. 높이는 계획상 상한을 따랐으나 이미지에서 미터 치수를 검증했다고 주장하지 않는다. 본 검수는 마스터 승인/기준 갱신이 아니다.
