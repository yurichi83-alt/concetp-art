# 보정3 사전 점검
- 마스터2.7 / 실행1.8. 현재 요청과 승인 범위 유지. 새 마스터 변경/추가 없음.
- 내장 image_gen.imagegen 사용. 별도API·설치·전역 설정 없음.
- 실제 입력1장: 이미 열어 본 구조 가이드와 동일 바이트의 사본. 기존 결과를 기하 입력으로 보존하지 않는다.
- 새 전략: 스타일3장을 입력에서 제외하고 단일 가이드의 정사영/기단 깊이/출구 끝 개구를 강조. 아트·세계관 기준은 문장 적용.
- A4층: 작은1층/큰2층/작은기계3층/큰4층. B2층: 기계1층/큰 어긋난 생활2층.
- 승용차1+오픈베드픽업1, 소화전, 큰 패턴 타일, 포스터·낙서, 대형 쓰레기통+폐냉장고+폐세탁기+쓰레기 대응 확인.
- 낮/무광 마른 파손 도로/희소 종이 쓰레기. 유리 물결·굴절 금지와 온전한 면의 큰 붓색면 유지.
- 전체 베이스 두 단면, 정확히 두 열린 출구, 중앙과 접근 공간, 사람용 입구/지지/윗면 기능성 유지.
- 계획 사전 대조만 수행. 결과 PASS나 실제콜리전·치수·3면 정합 검증을 뜻하지 않는다.
