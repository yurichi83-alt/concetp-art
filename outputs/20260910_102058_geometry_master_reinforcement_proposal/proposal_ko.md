## 1. 이번 결과에 대한 판단

이번 결과는 구조 통과로 처리하면 안 된다. 직전 결과의 C01/C02/L03/L05 PASS는 베이스 전체 노출과 문틀 존재를 주로 확인했고, 베이스의 기본 입체 및 길목의 실질적인 여유 공간을 충분히 검증하지 못한 판단이었다. 이번 검토에서 해당 구조 판정은 철회한다. 원래 결과/검수 파일은 이력으로 남기고, 이 문서에서 재평가한다.

## 3. 마스터에 넣을 권장 문안

아래 7개 항목을 이번 **기하·동선 보강의 승인 대상**으로 제안한다.

**① 정육면체형 공통 공간을 먼저 정의한다.**

> 모든 장면은 하나의 정육면체형 가상 공간 안에 건물·소품·자연물을 배치한 독립형 디오라마로 설계한다. 기본은 정사각형 평면과 서로 직교하는 X/Y/Z 축이다. 바닥·뒤쪽 두 경계·건물·외벽·소품은 동일한 공간과 척도 안에 놓인다. 정육면체는 공간 구성의 기준 틀이며, 화면에 유리 상자나 여섯 개의 닫힌 벽을 그리라는 뜻이 아니다. 하부 단면 블록의 두께가 베이스 폭과 같아야 한다는 뜻도 아니다. 기본 외형의 변경은 사용자 명시 요청이 있을 때만 적용한다.

현재의 폭·깊이 자유도보다 정사각형/정육면체형 기본 틀을 강화하는 변경이다. 단순 문장 정리로 가장하지 않고 승인할 변경으로 분리한다. 정확한 미터 치수는 새로 고정하지 않는다.

**② 장면 전체에 단 하나의 카메라·투영 체계를 적용한다.**

> 베이스, 포장, 건축, 외벽, 출구는 모두 하나의 카메라로 설명되어야 한다. 정투영/평행투영에서는 같은 3D 방향의 직선이 화면에서도 평행해야 한다. 투시 투영에서는 같은 3D 방향의 선군이 일관된 소실점을 따르고, 수평 방향들의 소실점은 공통 지평선에 놓여야 한다. 정투영의 평행선 규칙과 투시의 수렴 규칙을 한 장면에서 물체별로 섞지 않는다. 의도적으로 회전한 물체는 다른 방향의 소실점을 가질 수 있으나 같은 카메라와 지평선에 종속되어야 한다.

권장 작업 기본은 일관된 평행투영 쿼터뷰다. 약한 투시 쿼터뷰를 선택할 경우에도 장면 전체에서 하나로 고정한다. 현재 승인되지 않은 렌즈/각도 수치를 임의로 영구 설정하지 않는다. 모든 선을 단 하나의 소실점으로 모으라는 지시는 사용하지 않는다.

**③ 베이스의 기본 입체는 직선·평면·대응 모서리로 검증한다.**

> 베이스 상부 기준면은 네 모서리를 가진 하나의 평면이며, 아래쪽 기준면은 같은 평면 형상을 일정한 깊이로 내린 것이다. 상단과 하단의 대응 꼭짓점은 공통 수직축으로 이어지고 카메라 쪽 두 절개면은 평면으로 연결된다. 요청하지 않은 곡면 테두리, 둥근 코너, 다각형으로 잘린 모서리, 비틀린 보행면, 근거 없는 단면 두께 변화는 불합격이다. 흙·파손·배관의 불규칙함은 단면 내부나 국소적 파손으로 표현하며 베이스 전체의 기본 입체를 변형하는 이유가 되지 않는다.

화면에서 모든 직각이 90도로 보여야 한다거나, 원근 때문에 줄어든 화면상 두께를 같게 맞추라는 뜻이 아니다. 실제 3D 기본 형상이 일관된 투영을 따르는지를 본다.

**④ 마스터02의 두 경계와 바닥 연결을 함께 보존한다.**

> 카메라 기준 뒤쪽 좌·우 경계는 같은 베이스의 인접한 두 뒤쪽 변 위에서 만나며, 공통 공간 틀에 맞는 직교 관계를 가진다. 각 경계에 외부로 이어지는 출구가 하나씩 있어야 한다. 벽을 건물·펜스·컨테이너·시설로 표현해도 바닥과 경계가 만나는 위치 및 연결 구조는 바뀌지 않는다. 건물 두 개의 동일한 L자 배치를 강제하는 규칙은 아니며, 모든 배치 변화는 이 공간 틀 안에서 해결한다.

도해의 파란색·아이콘·화살표·문자는 여전히 최종 아트에 복사하지 않는다. 대신 도해의 기본 입체와 경계 관계를 단순 장식으로 취급하지 않는다.

**⑤ 출구까지의 통로를 폭과 높이가 있는 보호 공간으로 먼저 잡는다.**

> 중앙 활동 공간에서 각 출구 문턱을 지나 외부 연결부까지 연속된 보행 공간을 먼저 확보한다. 바닥에 가느다란 빈 선이 보이거나 문틀만 보이는 것은 통과 근거가 아니다. 상자·잔해·난간·돌출 기계·케이블·문짝과 그 부피가 통로에 침범하지 않아야 한다. 굽은 길은 회전 구간의 여유 공간까지 확인한다. 외곽 배치는 통로 점유를 허용하지 않는다. 물체가 충돌하면 물체를 이동·축소·제거하거나 건물 배치를 다시 잡고, 길이나 베이스를 휘어 해결하지 않는다.

실측 폭은 장면 계획에서 사람 기준 스케일로 정하고, 최소 폭 하나만 넓게 그리는 대신 전체 구간에서 유지한다. 이번에 임의의 2m/2인 폭을 영구 수치로 확정하지 않는다. 핵심 경로가 가려져 판단할 수 없으면 PASS가 아니라 UNCERTAIN이다.

**⑥ 건물 내부도 배치 가능한 방과 이동 공간으로 설계한다.**

> 내부가 보이는 상점/시설은 입구, 연속 바닥, 내부 통로, 기능별 배치 공간과 뒷벽이 있는 실체적 방으로 계획한다. 외관 크기에 비해 내부가 얕은 진열 상자로 축소되거나 물건이 전면을 채워 이동할 수 없으면 불합격이다. 건물 기초·문턱·도로의 높이와 방향을 공통 기준면에서 맞춘다. 계획된 계단·경사·회전은 가능하지만 연결과 접지가 명확해야 하며, 생성 오류를 의도적인 단차로 해석하지 않는다.

**⑦ 기하·동선 통과 전에는 결과 전체를 합격 처리하지 않는다.**

> 검사 순서는 기본 입체 → 공통 투영 → 바닥/경계 연결 → 두 외부 통로 → 내부 동선 → 아트/세계관/요청 사항이다. 공간 항목 하나라도 FAIL이면 전체 결과는 needs_revision이고, 핵심을 확인할 수 없으면 uncertain이다. 분위기·소품·세계관이 잘 나와도 구조 실패를 상쇄하지 못한다. 베이스나 공통 원근이 잘못되면 실패 이미지의 기하를 보존하는 편집을 중단하고 원본01·02의 공간 틀로 재구성한다. 사용자 요청이 분석/검토만인 경우에는 자동 재생성하지 않는다.

C03/C04/L06를 추가하면 실행 규칙·project.json의 자동 구조 보정 대상 목록도 함께 맞춰야 한다. 단순히 검사표에만 새 항목을 쓰고 실행에서 빠뜨리지 않는다. 기존 상시 구조 보정 승인 범위의 적용 방법을 구체화하는 제안이며 외부 API/설치/비용 승인이 아니다.

## 5. 생성 절차 보강안

1. **기준 공간 준비:** 장면마다 기본 블록, 하나의 카메라, 두 경계와 출구, 빈 통로 및 건물 부피를 같은 좌표로 잡은 단순 구조안을 먼저 만든다. 기존 형태/카메라를 재사용할 때도 현재 배치가 통로를 침범하지 않는지 확인한다.
2. **형태 검증:** 직선/평면과 상·하단 대응을 확인하고 통로 보호 영역과 건물/소품 부피의 겹침을 검사한다. 입체 좌표나 간단한 3D 블록아웃에서 만든 도식은 이 단계에 유용하다.
3. **아트 적용:** 구조가 정리된 안내 이미지와 원본01·02를 구조 근거로 사용하고 03·04를 아트/세계관에 적용한다. 사용 가능한 이미지 입력 형식/개수를 확인해 실제 전달하고 역할을 기록한다. 글로 “틀리지 않게”만 지시하고 보장을 주장하지 않는다.
4. **최종 재검사:** 생성 모델이 구조 안내를 바꿀 수 있으므로 결과의 기본 모서리/주요 선군과 통로를 다시 대조한다. 구조안이 맞았다는 사실을 최종 결과의 PASS 근거로 대체하지 않는다.
5. **국소/전체 오류 분리:** 작은 출구 장애물은 해당 부분 편집. 베이스·바닥·여러 건물의 원근이 함께 어긋나면 전체 공간을 재구성. 단순 줌아웃으로 기하가 수정됐다고 판단하지 않는다.

이 절차는 오류 없는 출력 자체를 보장한다는 뜻이 아니다. **구조가 틀린 결과를 최종 합격으로 전달하지 않도록 하는 기준**이다. 생성/편집 기능의 한계로 확인이나 수정이 안 되면 검수 한계를 명시하며 PASS로 바꾸지 않는다.
