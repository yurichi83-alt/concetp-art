# 이번 호출에서 확인한 입력 제한

첫 요청은 구조 가이드, M01-01, M02-01, M03-10, M04-02, 사용자 기계, B03-01의 7개 경로를 제출했다. 런타임 검증이 `referenced_image_paths must contain at most 5 paths`로 거절했으며 이미지는 생성되지 않았다.

현재 호출 경로에서의 최대5개가 이 오류로 확인됐다. 이는 최근 대화 이미지 선택 인자의 제한을 추정해 옮긴 값이 아니다. 모델 내부 버전·토큰 예산·참조 가중치·재작성 여부는 여전히 미확인이다.

재요청에는 구조 가이드 / M03-10 / M04-02 / 사용자 기계 / B03-01의 5개 이미지를 실제 경로로 제출했다. M01/M02 원본은 실제 확인했지만 재요청에는 첨부하지 않았고, 기본베이스·두단면·공통정사영·두후방경계·두기능출구의 역할을 구조안/가이드/프롬프트로 유지했다. 최초 요청 지시문은 generation_prompt.md, 실제5개 재요청 지시문은 generation_prompt_5refs.md다.

새 기계 디자인·마스터 스타일·붓터치 자료·세계관을 각각 유지하면서 확인된 장수에 맞췄다. 원본 마스터나 기본 참조 우선순위를 갱신하지 않았다. 생성 예시 B03-02~04나 다른 이전 출력은 어느 요청에도 넣지 않았다.
