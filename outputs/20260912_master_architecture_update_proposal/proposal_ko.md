# 건축 형태·곡면 경계 보강 — 마스터 갱신안
상태: 제안 / 미반영. 작성일: 2026-09-12.
현재 기준: 마스터 세트2.6 / 실행1.7. 이번 요청은 갱신 내용의 정리이며 실제 기준·참조 등록·승인 기록은 변경하지 않는다.

## 1. 갱신 목표
건축의 개성을 큰 형태, 외벽 깊이, 층별 구성과 생활/설비의 결합으로 만든다. 사용자가 만족한 곡면 슬럼2장과 낮 시가지2장의 형태 방향을 다음 키워드에도 적용할 수 있는 설계 원칙으로 정리한다. 특정 생성물의 배치/카메라/결함을 고정하는 갱신은 아니다.

원본27장 및 Little Devil Inside의 건축·재질·라이팅·색 표현과 Salvage Cyberpunk 세계관은 유지한다. 넓고 깨끗한 기본 색면, 큰 성긴 평면 붓터치, 선택적인 큰 수리/교체 흔적도 유지한다. 첨부 LDI5장의 승인 범위와 M03-12 자연물 제외는 그대로다.

## 2. 건물 지상 곡면 허용 — 기존 금지 문구를 교체할 항목
제안 문안:

> 건물의 주된 배치와 직선 구조는 공통 X/Y축을 기준으로 한다. 지상 외벽에도 둥근 모서리, 곡면 외장, 둥근 기계형 건축을 허용한다. 보행 영역과 차단 영역이 화면에서 자연스럽게 구분되어야 하며, 경계가 불명확한 좁은 쐐기 틈이나 납득하기 어려운 접합을 만들지 않는다. 임의로 비스듬히 회전한 건물로 개성을 대신하지 않는다. 곡면의 접선은 직선 축 검사 대상과 구분한다.

사용자의 원래 직교 제한 의도는 애매한 사선 보행 경계를 피하려는 것이었다. 곡면까지 전면 금지할 필요가 없다는 이번 시험 결과를 반영한다.
- 곡면을 보존하기 위해 모든 건물을 큰 사각 받침으로 감싸지 않는다. 국소 기초·지지대·난간은 필요한 곳에만 쓴다.
- 곡면 비율/반지름/곡선 건물 수의 전역 수치나 모든 건물 곡면 의무를 만들지 않는다.
- 건물 곡면 허용은 기본 디오라마 베이스의 둥근 테두리·모따기·뒤틀림 허용으로 확대하지 않는다.
- 실제 콜리전 제작·검사는 하지 않는다. 이미지에서 경계와 접지가 납득되는지를 본다. 콜리전 미검증을 이미지 보류/실패 이유로 삼지 않는다.

## 3. 건축 다양성 — 이미 허용된 항목을 실행 설계에 반영
설계 순서를 큰 형태 → 외벽/기능 공간의 깊이 → 표면 표현으로 둔다.
- ㄱ/L/T/U형, 길이와 폭이 다른 날개, 높은 본체와 낮은 부속 공간.
- 상층 후퇴·돌출, 깊은 창과 출입구, 부속실, 발코니, 외부 계단과 작업 데크.
- 경사·박공·톱니·곡면 지붕, 지붕 높이 차이, 차양과 설비의 결합.
- 용도·증축·수리 이력이 건물의 형태를 결정하도록 한다. 모든 건물에 모든 항목을 넣거나 같은 조합을 순환하지 않는다.

색상·층수·위치·작은 부품만 달라지고 주된 몸체는 반복되는 결과를 피한다. 같은 직육면체를 사용하더라도 외벽의 깊이와 큰 기능 부위를 통해 차이를 만들 수 있다. 정사영 보정 과정에서 승인받은 곡면·돌출·ㄱ자 형태를 전부 단순 상자로 되돌리지 않는다.

## 4. 기계와 건축의 결합 — 세계관의 형태 표현
제안 문안:

> 기계는 건물의 외벽 장식에만 머물지 않고 큰 외장, 구조 프레임, 별도 설비 동, 특정 층의 주된 부피를 구성할 수 있다. 회수한 장비의 지지·연결·수리·현재 용도가 읽혀야 한다.

- '2층이 기계 구조물'은 주거2층 위에 기계를 조금 올리는 것이 아니라 해당 층 자체가 비거주 설비 부피가 되도록 해석한다.
- 위 개념은 사용자가 지정하거나 장소 기능에 맞을 때 쓰는 선택지다. 앞으로 모든 건물의2층을 기계화하는 규칙이 아니다.
- '1층40%/2층20%' 등 요청한 기계 비중과 건물별 지붕40~80% 구성은 서로 다른 조건이다. 요청한 비중은 해당 장면에만 적용한다.
- 기존 지붕40~80%의 기능적 구성/지지/여백 원칙은 유지한다. 기계층 상부에 규칙을 맞춘다는 이유로 또 기계를 중복 증식시키거나 같은 탱크·패널 세트를 강제하지 않는다.
- 밝은 낮 시가지에서도 낡은 기술을 회수해 고쳐 쓰는 흔적이 읽혀야 한다. 청결한 색면을 새것/신품 세계로 해석하지 않는다.

## 5. 차단 경계와 출구의 다양성 — 기존 기능 규칙을 실제 활용
- 뒤쪽 두 방향에 기능 출구 하나씩, 총2개를 유지한다. 위치를 각 끝에 고정하거나 형식을 의무적으로 교대하지 않는다.
- 경계는 건물·담·대형 설비·연결된 구조물·컨테이너·차량·옹벽 등 장소에 맞는 대상으로 구성할 수 있다. 실제로 통과를 막아 보이는 연속성이 필요하며 낮은 소품을 놓았다는 이유만으로 차단 경계로 인정하지 않는다.
- 출구는 건물 문/셔터 겸용, 건물 사이 골목, 계단과 착지부, 지하 램프, 설비 사이/아래 통로 등으로 설계한다.
- 닫힌 전환문은 의도된 상태로 둘 수 있다. 열린 통로를 펜스·재고·난간으로 막은 오류를 닫힌 출구로 소급 해석하지 않는다.
- 중앙 공간과 출구 접근을 비우되 모든 장소가 같은 거대한 빈 마당으로 보이지 않도록 길 폭·건물 관계·주변 점유를 장소별로 설계한다.
- '시가지'를 '상점가', '슬럼', '유럽풍 점포' 또는 특정 건물 수로 자동 고정하지 않는다.

## 6. 공통 투영과 검수 — 유지 및 역할 명확화
- 최종 단일 정사영, 정사각 베이스, 일정 깊이의 두 전면 단면, 전체 프레이밍을 유지한다.
- 건물 기단·층 바닥·셔터 가로선·테라스 수평 보·상층 외벽을 바닥의 같은 방향과 대조한다. 건물만 더 정면/낮은 시점으로 그려지는 오류를 형태 다양성으로 허용하지 않는다.
- 수평 구조선, 실제 경사 지붕, 곡면 접선, 단순 가림을 구분한다. 건물 내부의 선이 대체로 일관돼도 장면 바닥과 어긋나는 공통 투영 오류일 수 있다.
- 기단이 가려진 상태에서 실제 건물의 평면 회전각·벽 기울기를 단정하지 않는다. 검수에 필요한 모서리를 소품으로 전부 가리지 않는다.
- 사용자가 후속3D에서 처리할 콜리전·메시·UV 검증을 현재 이미지 작업의 합격 조건으로 요구하지 않는다. 이미지에 보이는 접지·두께·지지·연결·동선은 계속 확인한다.
- 구조 오류 자동 보정과 실제 파일 검수는 유지한다. 진전 없는 같은 오류 반복은 중단 근거/미해결 상태를 남긴다. 이미지 생성 도구가 기하를 강제한다고 약속하지 않는다.
- 이번 결과에 남은 C04 정사영 오차는 허용 사례로 승격하지 않는다. 과거 리뷰/실패 이미지는 보존한다.

## 7. 장면 키워드 해석 — 테스트 내용을 전역 고정하지 않기
이번에 일반화할 것은 선택지를 활용하는 설계 방식이다. 아래 값은 해당 요청에만 적용한다.
- ㄱ자 건물, 기계가 차지하는 특정 층,2층 집의 절반 면적,40%/20% 비율.
- 건물2개/3개, 자동차·전봇대·쓰레기, 낮/밤/쿨 톤.
- 특정 건물 좌우 위치, 출구 조합, 같은 배관 단면, 차량 종류.
- 두 장 요청의 좌우 반전·재색칠을 독립 설계의 대체로 삼지 않는다. 장소/조건은 공유하되 큰 형태·배치·경계/연결의 차이가 읽히게 한다. 변화 개수나 필수 곡면 개수는 만들지 않는다.
