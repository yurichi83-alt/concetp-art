# 독립 생성 — 기본 골목 시안
요청: 도심 속 골목 / 낮 / 폐건물과 쓰레기통 / 바닥에 널린 쓰레기 / 한 장.
총2장의 첫 번째이며 카세트 시안과 서로 입력·생성 결과를 참조하지 않는 독립 신규 생성. 기본 Salvage Cyberpunk에 카세트 퓨처리즘 제외.
마스터2.3/실행1.4. 좌측 단계형 폐건물의 빈 지상 통과로가 좌측 기능 출구 겸 입구, 우측 탱크와 작은 폐관리동 사이 열린 골목이 우측 기능 출구. 모두 클리어 후 개방 상태. 관리동의 문은 닫힌 장식 입구.
건물 외곽선은 X/Y직교, 원통 탱크는 비건물 경계물. 탱크에는 건물 입구/옥상비율 요구 미적용.
각 건물 지붕에 약58%/55% 기능설비 계획, 수치 검증은 구조안 범위. 직선 정사각형 베이스에 양면 토층·기초·설비 단면.
개별20% 기계화율은 이 요청에서 지정하지 않아 강제하지 않음.
실제 입력은 새 구조안과 M02/M01/M03/M04. 과거 생성물·이번 다른 출력·카세트 참고는 입력하지 않음.
