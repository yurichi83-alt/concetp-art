# 사전 확인
- 내장 image_gen 사용, 이 run 최종1장. 독립된 두 시안 중 기본안.
- 5개 입력 파일 모두 실제 열어 확인. 원본 해시 검증.
- 건물 외곽선 각 선분 X/Y축 검사 PASS. 보호 보행 부피와 건물/소품 교차0.
- 지붕은 평면 받침과 통과로 상부보로 지지. 최종 이미지의 지붕/벽 정합은 별도검수.
- 출구 역할/위치/형태/개방 상태/연결을 structure_plan.json에 기록.
- 최종C01~C04/L01~L07, W04/W05 검수 후 전달. 실제 이미지 오류는 승인된 구조보정 범위에서 수정.
