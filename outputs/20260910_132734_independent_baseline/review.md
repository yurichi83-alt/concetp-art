# 기본안 최종 시각 검수
상태 candidate_pass. 실제 생성 PNG를 확인. 사용자 승인/마스터 승격 아님.
C01 PASS: 전체 정사각 베이스·연결 경계·건물/탱크가 프레임 여백 안에 보임.
C02 PASS: 두 전면 평면 단면에 토층·기초 기둥·배관/전선이 보임, 대응 모서리/두께 일관.
C03 PASS: 베이스는 직선 사각 프리즘, 임의 사선 절단/곡률/추가면 없음.
C04 PASS: 포장·건물·경계·기초의 주요 선군 공통 쿼터뷰. 지붕은 높이가 다른 평면으로 읽힘.
L01 PASS: 건물·벽 조합과 탱크/관리동이 뒤쪽 좌우 경계 방향을 구성.
L02 PASS: 왼쪽 건물 하부 관통 통로와 오른쪽 탱크-관리동 사이 열린 골목이 두 기능 출구. 관리동 닫힌 문은 장식입구.
L03 PASS: 왼쪽 통로 전면 접근 폭, 통로 바닥/측벽/상부보와 너머 밝은바닥 확인; 안쪽 높은 장애물 없음. 오른쪽 탱크와 관리동 사이로 넓은 바닥이 이어져 후방 연결 보임. 큰 쓰레기는 문턱/통로 밖에 있음.
L04 PASS: 전면 바닥과 단면을 가리는 높은 구조물 없음.
L05 PASS: 건물/문/탱크 받침의 접지, 통과로 상부보의 측벽 지지, 지붕 장비 받침 확인.
L06 PASS(관통 구간만): 좌측 통로는 입구에서 반대편 빛까지 길이·높이·빈 바닥이 읽힘. 장식관리동 내부는 비노출로 해당 없음.
L07 PASS: 건물 평면의 접촉외벽과 후퇴가 공통 X/Y 직각. 원통 탱크는 비건물 예외, 보행을 사선 건물벽으로 유도하지 않음.
W04 PASS: 큰 건물은 기능출구 통로가 입구 겸용, 관리동은 사람용 닫힌문. 탱크에는 적용하지 않음.
W05 PASS(시각추정): 큰 건물 두 높이의 옥상에 장비·덕트·배관 구성, 관리동은 장치·후면 서비스구조와 여백. 건물별 요구범위와 양립하는 점유로 보이나 정확한 픽셀면적 측정은 아님.
R01 PASS: 낮/폐건물/두 쓰레기통/바닥 종이·포장재·봉투 등 확인. 카세트 퓨처리즘 제외한 기본 Salvage Cyberpunk.
독립성: 새 구조도와 M02/M01/M03/M04만 입력, 다른 시안이나 과거 생성물을 입력하지 않음.
아트 한계: 마스터보다 일부 바닥/벽 오염은 상세한 편. 기계에는 통일된 카세트 계기/카트리지/주황 손잡이 없음.
수치 높이·콜라이더·카메라 역산은 미검증이며 시각적 기하·동선 근거로 평가.

별도 시각 검수: baseline_visual_review가 최종 PNG만 독립 확인. 직선 평면 베이스와 설비 단면, 공통 투영으로 읽히는 직교 건물, 좌측 관통 통로·우측 탱크와 관리동 사이 골목의 접근 가능성, 닫힌 관리동 문, 지붕 지지와 중앙의 낮은 장애물 상태를 확인. 중대한 가시적 구조 오류를 발견하지 않음. 옥상 점유는 시각적 추정이며 정확한 면적 측정이 아님.
