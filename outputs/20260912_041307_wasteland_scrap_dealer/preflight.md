- 건축·설비 용도/큰형태/깊이를 먼저 설계. 직전 시가지의 건물 수/층별비율/차량/날씨/단면을 자동상속하지 않음.

- 실제콜리전·메시·UV 미검증은 이미지불합격아님. 시각적접지·기단·공통축/곡면/지붕접합·동선은 최종PNG에서검사. 관찰된구조오류는상시승인범위에서만보정, 이전시도보존.

독립 사전 검토: 배송진입과 프레임아래통로의 기능/깊이 구분, 연속적인높은고철경계, 작업장상부/계단지지, 큰슬랩/흙의차이와깨끗한표면을 확인하도록 보강했다. 도구 경로5장 상한이라는 제안은 현재 노출계약 근거가 없어 채택하지 않았다.

최종 사전 점검: 수정된 structure_guide.png를 직접 열람했다. 원형 구동부/기어가 있는 비건물 분류기, 깊이 있는 설비 데크 아래 출구, 길 바깥 기둥, 전체 사각 단면과 공통 축을 확인했다. 생성 실행 가능. 이 검사는 아직 생성되지 않은 최종 이미지의 QA가 아니다.

실행 시 확인한 도구 제한: 7개 로컬 경로 호출은 생성 전 인자 검증에서 거절되어 실제 최대5개를 확인했다(tool_rejection.json). 실행 입력은 구조가이드/M03-10/M04-02/F-04/B03-01의5장으로 조정했다. M01/M02는 직접 열람·구조 설계에 반영했지만 재호출 이미지 입력에서는 제외한다. 도해 역할은 새 구조가이드와 명시적 구조 지시가 담당한다. 위7장 계획/번호는 최초 사전 계획의 이력이며 실제 입력은 tool_arguments.json이 기준이다.
