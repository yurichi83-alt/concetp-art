## 검사 순서
기본 입체 → 공통 투영/지붕 면 정합 → 건물 직선축과 곡면 경계 → 바닥/경계 접합 → 두 기능 출구의 상태별 동선 → 해당 내부 동선 → 큰 기능 부피·외벽 깊이 → 표면·빛·재질 → 세계관 → 개별 요청·수정 전후 보존.
구조안의 사전 검사와 실제 최종 이미지 검사를 따로 기록한다. 계획 PASS, 프롬프트의 규칙, 단순 경계상자(AABB) 무충돌은 최종 PASS의 근거가 아니다. 저장된 실제 이미지를 열고 아래 필수 정사영 대조를 수행한다. 프롬프트에 orthographic이 있다는 사실만으로 최종 정사영을 PASS 처리하지 않는다.
이미지를 열 수 없으면 `NOT_REVIEWED`; 애매하면 `UNCERTAIN`으로 남긴다.
장면의 요구사항 원장에서 사용자 원문/적용 마스터 → 반드시 보여야 할 모습 → 실제 프롬프트의 정확한 구절 → 담당 참조 또는 설계 근거 → 최종 관찰 영역과 판정을 잇는다. 구역명이나 '기계층 있음' 같은 포괄 문장만으로 개별 기능 부피·붓표현·표면 금지 조건까지 확인했다고 쓰지 않는다. 문서·참조·도구 입력·관찰 결과는 각기 다른 증거이며 입력 기록의 무결성 검사가 이미지 품질을 판정하지 않는다.

S01은 넓은 면의 정돈 여부를 보고 건물의 신품 여부와 분리한다. W02는 큰 파손·보수·교체·우회 공급 등 실제 환경의 흔적으로 확인한다. W03은 승인된 낮 골목 보강 시안의 기계 비중을 필요한 경우 비교하되 수치 비율이나 장치 복제를 요구하지 않는다. 기계가 외장·프레임·설비 동·한 층 자체를 이루는 것은 사용자 지정/장소 기능에 맞는 선택지이며 모든 건물의 기계층 의무가 아니다. '1층40%/2층20%' 같은 요청 비중은 그 장면에만 적용하고 옥상40~80%와 분리해 검사한다.

R02는 새 장소와 독립 시안 요청에 적용하고 기존 장면의 명시적 편집에는 NOT_APPLICABLE로 기록한다. 실제 결과의 윤곽·층별 부피·후퇴/돌출·외벽 깊이·용도와 길 폭/인접 건물/경계/출구의 관계를 비교해 차이를 설명한다. 조명/색·층수/위치 교환·작은 부품 수나 '새로 설계함/다른 결과를 입력하지 않음'만으로 PASS를 주지 않는다. 같은 직육면체를 사용해도 깊이와 큰 기능 부위로 차이가 날 수 있고, 모든 항목을 바꾸거나 정량 변화 개수/곡면 개수를 채울 의무는 없다. 중앙이 열려 있다는 이유만으로 모든 장소를 같은 거대한 빈 마당으로 만드는 것도 적합 근거가 아니다. 동일 시안의 보정 전후는 R02 대신 R03으로 검사한다.

R03은 편집 대상/이전 run과 보정본의 실제 이미지를 함께 열어 검사한다. 유지할 주요 날개·돌출 하우징·깊은 서비스 홈·굵은 지지 등 해당 시안의 기능 부위를 이름과 관찰 영역으로 특정한다. 보정 목표와 보존 대상을 나누고, 큰 기능 부피·깊이를 층수/기계층/곡면의 유무와 따로 비교한다. 구조·표면·빛/재질·세계관·현재 요청의 개선/유지/후퇴/불확실을 기록하며 앞선 관찰 오류 자체를 보존 대상으로 삼지 않는다. 명시적으로 바꾸라고 한 부분은 그 요청에 맞춰 평가한다. 이전에 목표에 미달했던 붓표현이 그대로라는 사실은 R03의 '후퇴 없음'일 수 있으나 S01/S03 PASS나 전체 완료의 근거는 아니다.

`master_update_20260911_v2_6_brush_planes`의 붓질은 목표 표현이다. 손상 없는 넓은 면에서도 가까운 톤의 크고 성긴 방향성 평면 터치가 읽혀야 하며, 표면 색 변화와 녹·오염·박리의 양을 따로 본다. 넓은 기본색의 여백과 큰 명암·재질·윤곽·두께·접지를 함께 유지한다. 붓 크기·면적 비율·톤 수의 수치 임계값은 만들지 않는다. S03는 긍정 붓표현과 금지 패턴의 두 근거가 모두 필요하고, '패치가 조금 있음' 또는 '실제 유리는 아님'만으로 통과시키지 않는다. 재질에 맞는 물·유리의 국소 반사는 허용하지만, 마른 포장 등에 물결처럼 읽히는 가는 구불거림·긁힘·얼룩이나 비슷한 균열 군집이 반복되면 보이는 표현 자체로 FAIL이다. 물리적 굴절·유리 셰이더·노멀맵이나 바닥 곡률이 실제 사용되었다고 단정할 필요도 근거도 없다.

- 실제3D 치수/콜리전/메시/UV 미검증은 현재 이미지 실패·보류 사유가 아니며, 눈에 보이는 차단/비틀림을 면제하는 근거도 아니다. 적용되는 이미지 관찰 항목을 NOT_REVIEWED로 남겨 놓고 최종 구조 통과로 보고하지 않는다.

**전체 완료는 C01~C04·L01~L07·S01~S04·W01~W05·R01~R03 중 모든 적용 항목을 통과한 경우다.** 명시된 마스터·현재 사용자 요건의 관찰 가능한 기준을 근거로 판단하며, 하나라도 FAIL이면 전체 `needs_revision`이다. FAIL이 없더라도 핵심 불확실이 남으면 `uncertain`, 실제 결과나 적용 검사를 열람하지 못했으면 그 항목은 `not_reviewed`로 남기고 완료로 보고하지 않는다. 미해당 N/A는 사유가 있어야 하며 검사 생략이나 실패 회피에 사용하지 않는다.

구조/출구 개선이 큰 기능 부피·깊이, 붓표현, 도로표면, 빛·재질, 세계관 또는 현재 요청의 실패·후퇴를 상쇄하지 않는다. 이 항목들을 후보별로 나란히 비교하고 최신 보정본을 자동 선택하지 않는다. 전체 통과본이 없으면 그 사실과 후보 선택 근거를 공개한다. `outputs/final/`에 전달본을 보관하는 것은 전체 완료·QA 통과·마스터 승격과 별개다.

## 상태
- `candidate_pass`: 모든 적용 C/L/S/W/R 기준이 최종 관찰 근거로 PASS이고 미해당 사유가 기록된 전체 통과 후보. 사용자 승인 아님.

## 실패에 따른 대응
구도/단면이 완전히 틀리면 실패 이미지 보존 편집에 집착하지 말고01·02를 기반으로 재구성한다. 잘못된 투영·접합을 고치면서 현재 요청/승인된 곡면·돌출·ㄱ자·외벽 깊이·기능적 개성을 유지할 형태로 다시 설계한다. 보정 가이드를 단순 상자로 되돌리는 것은 해결책이 아니다.
공간이 적합하고 표면만 실패하면 현재 이미지를 대상으로 표면을 편집하며 구도·큰 기능 부피·깊이·요청 요소를 보존 대상으로 기록한다. 내장 편집이 영역/픽셀 보존을 강제한다고 약속하지 않고 실제 결과에서 다시 비교한다.
출구 한 곳만 누락됐으면 주변 경계만 수정하고 다른 공간/스타일의 변형 여부를 다시 본다.

한 번의 보정에서 변경 요인을 제한한다. 참조 제거·카메라·문장·형태를 동시에 바꾸고 특정 조치가 개선의 원인이었다고 단정하지 않는다. 구조와 아트/세계관/표면의 실제 시각 근거를 역할별로 유지하고, 참조 카메라 영향이라는 미검증 가설만으로 아트 입력을 전부 제거하는 것을 기본 해결책으로 삼지 않는다. 실제 입력 한도와 선택·생략 이유는05의 기록 절차를 따른다.
