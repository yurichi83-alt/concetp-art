# 결과 검수와 승인 — 마스터 v2.7 / 실행 v1.8

> 기준 관계: 마스터 01~04 v2.7와 원본 19장+승인된 LDI 보강 5장+사용자 추가 3장(총27장)이 기준이다. Little Devil Inside 아트 표현(세계관 제외)과 Salvage Cyberpunk 세계관은 고정한다. A-01/A-02, 별도 색면·붓터치 보조 B03-01~04와 건축 형태 보강 F-01~07/형태 비교 F-08~11은 승인된 속성만 참고하며 마스터27장이나 기존 기본 우선순위를 대체하지 않는다. 상세: `docs/10_CURRENT_REFERENCES.md`.

원본 마스터 적합성을 먼저 검수하고 A-01/A-02의 선호 결과 인상도 함께 비교한다. 선호 예시를 원본 마스터의 대체 기준으로 삼지 않으며, 디테일 개수만으로 기계적으로 판정하지 않는다.

## 검사 순서
기본 입체 → 공통 투영/지붕 면 정합 → 건물 직선축과 곡면 경계 → 바닥/경계 접합 → 두 기능 출구의 상태별 동선 → 해당 내부 동선 → 스타일 → 세계관 → 개별 요청.
구조안의 사전 검사와 실제 최종 이미지 검사를 따로 기록한다. 계획 PASS, 프롬프트의 규칙, 단순 경계상자(AABB) 무충돌은 최종 PASS의 근거가 아니다. 저장된 실제 이미지를 열고 아래 필수 정사영 대조를 수행한다. 프롬프트에 orthographic이 있다는 사실만으로 최종 정사영을 PASS 처리하지 않는다.
이미지를 열 수 없으면 `NOT_REVIEWED`; 애매하면 `UNCERTAIN`으로 남긴다.

S01은 넓은 면의 정돈 여부를 보고 건물의 신품 여부와 분리한다. W02는 큰 파손·보수·교체·우회 공급 등 실제 환경의 흔적으로 확인한다. W03은 승인된 낮 골목 보강 시안의 기계 비중을 필요한 경우 비교하되 수치 비율이나 장치 복제를 요구하지 않는다. 기계가 외장·프레임·설비 동·한 층 자체를 이루는 것은 사용자 지정/장소 기능에 맞는 선택지이며 모든 건물의 기계층 의무가 아니다. '1층40%/2층20%' 같은 요청 비중은 그 장면에만 적용하고 옥상40~80%와 분리해 검사한다.

R02는 새 장소와 독립 시안 요청에 적용하고 기존 장면의 명시적 편집에는 NOT_APPLICABLE로 기록한다. 실제 결과의 윤곽·층별 부피·후퇴/돌출·외벽 깊이·용도와 길 폭/인접 건물/경계/출구의 관계를 비교해 차이를 설명한다. 조명/색·층수/위치 교환·작은 부품 수나 '새로 설계함/다른 결과를 입력하지 않음'만으로 PASS를 주지 않는다. 같은 직육면체를 사용해도 깊이와 큰 기능 부위로 차이가 날 수 있고, 모든 항목을 바꾸거나 정량 변화 개수/곡면 개수를 채울 의무는 없다. 중앙이 열려 있다는 이유만으로 모든 장소를 같은 거대한 빈 마당으로 만드는 것도 적합 근거가 아니다. R02 보강은 C01~C04/L01~L07의 구조 자동 보정 범위를 확대하지 않는다.

`master_update_20260911_v2_6_brush_planes`에 따라 붓질 자체는 실패가 아니다. 손상 없는 면에도 가까운 톤의 큰 평면 터치를 사용할 수 있으며, 표면 색 변화와 녹·오염·박리의 양을 따로 본다. 벽·바닥·차체·기계 외장에서 기본색의 여백, 터치의 규모/방향, 큰 명암, 재질 차이와 윤곽·두께·접지의 가독성을 함께 확인한다. 붓 크기·면적 비율·톤 수의 수치 임계값은 만들지 않는다. 재질에 맞는 물·유리의 국소 반사를 붓터치의 유리 같은 요철 오류와 혼동하지 않는다.

B03-01~04는 이 표면 표현만 설명한다. 특히 생성 예시 B03-02~04의 선호는 기하·배치·출구·전체 QA 승인이 아니며 남아 있는 오류를 합격 기준으로 삼지 않는다. 밤·특정 색상·흰 조명·손상량 절반도 전역 합격 조건이 아니다. 이번 표면 보강은 기존 구조 판정과 자동 보정 범위를 바꾸지 않는다.

`master_update_20260912_v2_7_architecture_forms`에 따라 F-01~07은 큰 형태·외벽 깊이 등의 선택 건축 형태 입력(`scoped_architecture_form`, `generation_input_allowed=true`, `default_generation_input=false`)이다. F-08~11은 승인된 형태 선호의 비교 전용(`scoped_architecture_example`, `generation_input_allowed=false`, `default_generation_input=false`, `geometry_approved=false`)이며 기존 `needs_revision`을 유지한다. 형태 선호는 카메라·배치·통로·정량 비율·전체 QA 승인이 아니고 C04 오차를 허용 사례로 승격하지 않는다. 첨부7장의 원근·미세 질감·실사 밀도·네온·초고층 높이·수상 베이스·상호/인물도 승인 범위 밖이다. 원본27장과 표면 보조4장/형태 자료는 별도 분류이며 LDI라고 출처를 추정하지 않는다.

고저차·계단·램프·경사지붕은 연결·접지와 시각적 보행/차단 구분을 지키면 허용한다. 건물의 주된 배치와 직선 구조·계단/램프의 평면 진행은 공통 X/Y축을 기준으로 하며, 지상 둥근 모서리·곡면 외장·둥근 기계형 건축도 허용한다. L/T/U형, 후퇴/돌출, 발코니·외부 계단·작업 데크, 높이와 경사/박공/톱니/곡면 지붕 변화로 다양화한다. 곡면 접선은 공통 직선축과 평행할 의무가 없고 곡면 건물을 큰 사각 받침으로 감쌀 의무도 없다. 필요한 국소 기초/지지와 접지·경계 연속성을 확인한다. 형상 자유로 베이스 모따기/곡률/비틀림이나 임의 회전 건물·불명확한 쐐기 틈을 허용하지 않는다. 원본02를 동일 건물/담 두 줄이나 단일 높이로 축소하지 않는다. 소품·차량·원통 탱크도 본래 곡면/회전과 공통 투영·접지·차단 역할·통로 보존을 검사한다. 건물이 없는 장면은 L07에 N/A 근거를 남긴다.

출구 위치는 각 면의 중앙·중간·끝 모두 가능하며 고정 좌표나 강제 교대 순서가 아니다. 건물 입구/내부 전환, 건물 사이 골목과 개폐 철문, 계단/시설 통로, 지하 주차장 램프 등의 기능을 판정한다. 모든 출구에 독립 문틀과 문턱 너머의 노출 바닥을 요구하지 않는다. 닫힌 출구는 접근 공간·개방 장치의 여유·클리어 후 연결 계획을 확인하고, 열린 출구는 실제 보이는 연결 동선의 장애물을 확인한다. 전환 대상인 건물 내부 전체가 숨겨졌다는 이유만으로 실패시키지는 않되 입구 규모/접근/기능이 모호하면 UNCERTAIN이다. 지정 후방 출구의 지하 진입과 전면 토층 절개의 제3출구화를 구분한다.
